# 资产缩略图条实施记录（2026-10-10）

## 来源

老大报：**「会出现上传的图片再打开无法查看的情况」**。

## 根因（实测，非推断）

先排除持久化层，再定位到渲染层。Playwright 走真实 UI 的三态取证：

| 时点 | 面板内 `<img>` 数 | 数据状态 |
|---|---|---|
| 导入后 | **0** | 库中 1 张，下拉可见「林夏_正面.png」 |
| 手点下拉选一张 | 1（`dataUrl` 正常） | 本段已选 1 |
| reload 后 | **0** | 本段已选 1（绑定还在，图看不到） |

- **不是持久化问题**：真实 IndexedDB 下 `saveDraft → loadDraft` **完全可逆** —— `assets = 1`、
  `dataUrl` 完整、`failed = false`，`drafts` 与 `images` 两个 store 各 1 条。图一直在硬盘上。
- **根因在渲染层**：全应用只有 `AssetPane.renderEditor` 一处渲染缩略图（`Thumb`）与
  `renderEditor` 的编辑区，而编辑区由**组件局部 state `editing`** 控制：
  - `pickImages` 导入只入库（`store.addImages`），**不设置 `editing`** → 导入后看不到图；
  - `editing` 不落盘，重载后必然为 `null` → 再打开必然看不到图；
  - 下拉 `<option>` 与「已选标签」只能放文字，放不下缩略图。
- **属回归**：2026-10-06 那次改版（三框并列 → 下拉 + 已选标签）删掉了每张卡的
  `.image-item` 缩略图，缩略图就此只剩编辑区一处；旧形态下每张卡都有缩略图。

## 实施范围

最小面：`src/panes/AssetPane.tsx` + `src/styles.css`（**不动数据层、不动持久化、不动匹配**）。

- **每类补一条始终可见的 `.asset-strip` 缩略图条**，位于「已选标签」与描述编辑区之间。
  条内列出该类**全部**资产（不只是已绑定的）：已绑定本段的加 `.bound` 高亮，
  当前编辑对象加 `.editing` 描边。
- **点一下 = 复用唯一出口 `pickForSegment`**（选为本段 + 打开编辑区）——
  只增加「看得见」这一件事，**不新增第二种选图语义**（守住 2026-10-06「选图只有一个出口」的裁定）。
- 条内的图复用既有 `Thumb`（`IntersectionObserver` 近视口才挂 `src`）：条再长也不会在打开存档时
  按原分辨率解码，性能纪律不变。
- 描述编辑区**保留**（描述仍是 ①② 的取值来源；这里只补「图看不见」这一件事）。
- 缩略图条的 `aria-label` 取 `${name}缩略图条`，**刻意不含「资产」二字** —— 分组容器是
  `${name}资产`，而 `getByLabel` 默认是**子串匹配**，含「资产」会与之撞车（同「密钥 / 本机密钥状态」的坑）。

## 验证

- **e2e 新增回归锁**：`reference thumbnails stay visible after import and after reload` ——
  断言**两个时点**的 `naturalWidth > 0`。刻意不数节点：`src` 是近视口懒挂的，
  只数节点会漏掉「挂着空 `src` 的裂图」，而那正是用户看到的样子。
- **契约护栏**：`tests/方案文档.Tests.ps1` 新增一组（条的落点 / `pickForSegment` 复用 /
  `img` 限尺寸 / 归档与导航登记）。
- **复现口径留存**：临时 Playwright spec 里 `page.evaluate(() => import('/src/core/storage.ts'))`
  可在 vite dev server 下**直接驱动 src 模块**做端到端验证（不经 UI，成本极低）；
  跑法遵 `.workbuddy/memory/环境约束.md`（`--output=E:/wb_temp/pw-out-<用途>-<序号>` + 重定向日志 + `timeout`）。

## 剩余边界

- 图条只解决「**看得见**」。**镜级注入**（无人说话的段落里人物照常入画却拿不到描述、
  一人镜还会写出同段其他人的描述）是另一条线，登记在 v1.1 方案 §15，本轮不动。
- 未选中资产的**描述状态**仍只在条内的视觉提示（未写描述时标题带括注），不额外造状态字段。
