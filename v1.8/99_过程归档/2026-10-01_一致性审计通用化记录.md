# 一致性审计通用化记录

## 老大反馈（2026-10-01 · 七次）

> 「是做成**通用的**，不是针对某一剧本都要做专门的升级。如果每次都要这么检查一次，效率太低，做这个的意义就没了。」

前六轮的做法是「发现错位 → 写临时探针 → 量 → 修 → 删探针」。这解决了**这一部**剧本的问题，
但换一部剧本又要重来一遍 —— 审计能力没有沉淀进产品。本轮把它**机制化**。

## 做法：审计从「探针」搬进产品

| 层 | 新增 | 职责 |
| --- | --- | --- |
| 规则叶子模块 | `src/platforms/minimax-h3/rules.ts` | 转场禁词、单镜时长、**闸门分级表 `issuePolicy`** 下沉到最底层。原三者（`director` / `validator` / `audit`）互相 import 会成环，规则必须独立。 |
| 通用审计 | `src/platforms/minimax-h3/audit.ts` | `auditEpisodeContent(project, episode)`：**与具体剧本无关**的一致性检查，判据全部来自原稿本身与生成端同源函数，不含任何作品专属词表、集号或阈值调参。 |
| 校验接入 | `src/platforms/minimax-h3/validator.ts` | `validate()` 末尾自动执行审计 → 质检面板、按集导出闸门、全书阻断清单**自动获得**这些检查，无需额外操作。 |
| 一键体检 | `npm run audit:script -- "<剧本路径>"` | `scripts/audit-script.mjs` + `vitest.audit.config.ts` + `tests/audit/script.audit.test.ts`。与 `npm test`（`tests/unit/**`）隔离，换剧本只换路径、不改代码。 |

## 六类检查（新闸门编号已在 `issuePolicy` 登记）

| 编号 | 分级 | 判据 |
| --- | --- | --- |
| `AXIS_JUMP` | error / source | 同场次内同一人物在 ⑨ 中换侧 —— 越轴穿帮 |
| `TRANSITION_PREMISE` | error / source | ⑭ 命中了带前提的衔接条目但前提不成立（L-Cut 需本镜有台词、动作接动作需两侧都有抬手动作…） |
| `SPEAKER_UNTRUSTED` | error / source | ⑫ 说话人在原稿中无法确证（疑似叙述行被当成台词） |
| `BLOCKING_UNKNOWN_SUBJECT` | warning / review | ⑨ 写出名册与原稿说话人之外的主体（疑似叙述片段被当成人物） |
| `SCALE_SUBJECT_CONFLICT` | warning / review | ③ 景别为特写但入画 ≥2 人 |
| `STAGING_COMPOSITION_CONFLICT` | warning / review | ④ 构图与 ⑨ 站位把主体写到相反一侧 |

判据一律**保守**：只识别生成端 `stagingFor` 写出的三种站位写法与规则表内的衔接文案，
人工自创写法识别不到就跳过 —— 宁可漏报，不误报。

## 顺带修掉的两个真根因

1. **`isCastName` 的环境词是未锚定子串匹配 → 误杀真实说话人**。
   `environmentOnly` 含「灯光」，于是**「灯光师」永远进不了名册**：台词镜靠 `shotSpeakers` 兜底写得出来，
   但它之后由填充镜继承的 ⑨ 就写不出 —— 被新审计抓了个正着。
   修法：说话人子通道**不再做「像不像人名」的二次过滤**（解析器已按 `speakerTrusted` 筛过），
   人物设定块条目仍走完整判据（拦住 `椅子：一把旧木椅` 这类道具行）。**名册 62 → 68**。
2. **`compositionContradictsStaging` 实际永不触发**。旧实现用关键词包含判「左 / 右」，
   而站位文案同时含「位于画面**左**三分之一」与「身体朝向画面**右**侧」→ 两侧都命中 → 一律判「不矛盾」。
   修法：位置解析下沉为与 `stagingFor` **互为逆函数的单一来源** `sidesIn()`，只认位置表述、忽略朝向。

## 实测（真稿一键体检）

`npm run audit:script -- "…/倒查三代_全剧60集_定稿版剧本_20260930_v1.txt"`

```
[体检] 60 集 / 318 场景 / 4279 节拍 / 2066 台词 / 4512 镜 / 名册 68 人
[体检] 一致性问题合计 3（阻断 0）
[体检]   SCALE_SUBJECT_CONFLICT（warning/review）= 3
```

**耗时约 2.5 秒**（4512 镜），日常单测因配置隔离零影响。

- `npx vitest run` → **108/108** 全绿（新增 7 条审计用例：干净内容 0 问题 ＋ 六类问题各一条人为注入必被抓到 ＋ 一条证明 `validate()` 已自动接入）
- `npm run audit:script` → 真稿阻断 0
- 闸门分级表断言同步更新（`error` 清单新增 3 个编号）

## 剩余边界（待老大裁定）

- **E10 ③景别 × 入画人数**：情绪镜固定「面部特写」，真稿 3 例「特写里塞 2 人」。
  现在这条已被审计**自动暴露**（review 级，不阻断导出）。修法需新增景别档位文案（如「双人中近景」），属创作档位，未擅动。
- 字段编号旧写法漂移（`⑦站位` / `⑧肢体动作` / `⑨微表情`）仍是已登记漂移。
