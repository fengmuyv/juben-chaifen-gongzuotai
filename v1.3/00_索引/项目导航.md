## 实施资产

- `src/core/`：原稿结构、节拍、15 秒草稿规划、v2 版本化数据模型与 v1→v2 迁移。
- `src/core/episodes.ts`、`src/core/parser.ts`：整本分集识别、集清单与切点行号；分集切点单一来源 = `parser.episodeHeadingOf`（三态：真集标 / 集头导语），`episodes.ts` 不另写正则，真集标优先、同集号取最后切点。解析器含非正文块识别（`briefHeadings` 单一来源：来源 / 类型 / 人物设定 / 故事梗概 / 大纲 / 世界观等标题连同下属内容整体剔除）、`isMetadataLine` 元数据行过滤与人物名册提取（`speakerStem` + `isCastName`）。
- `src/core/storage.ts`：IndexedDB 持久化与 v1.0 浏览器草稿迁移。
- `src/core/analyze.ts`、`src/core/match.ts`、`src/core/pixels.ts`：本地图像分析（图类 / 主体 / 光影色彩）与三级置信度匹配。
- `src/platforms/minimax-h3/director.ts`：规则导演引擎。生成单一来源 —— 身体动作 / 面部动作 / 声音声源三张证据表驱动 ⑧ ⑨ ⑬，④ 构图与 ⑦ 站位由同一 `Staging` 派生；人物识别取真实姓名（8 条判据剔除部位词 / 数量副词 / 元数据词，双人分列左右三分之一）。⑧ ⑨ 原稿有证据优先取证，无证据时按「情绪档 `emotionDesigns` + 跨集人物弧光 `arcStages`」设计，仅空镜填「无」。⑬ 音效 = 原稿声源证据 ＋ 场景空间底噪（`ambienceCues` 具体地点 + `genericAmbience` 内外 / 昼夜兜底），按环境主题去重；场景无环境线索时仍填「无」。
- `src/platforms/minimax-h3/validator.ts`：单源闸门表 `issuePolicy`（事实类与内容安全阻断、人工确认转复核）与全部校验闸门。
- `src/platforms/minimax-h3/gate.ts`：按集导出审计（阻断项 / 复核项 / 可导出集），支撑全书阻断清单与按集导出。
- `src/core/migrate.ts`：v1.0 单集快照 → v1.1 多集结构迁移。
- `electron/script.ts`：可选 AI 文本增强通道与「测试连接」。
- `src/platforms/minimax-h3/`：H3 专属 14 字段骨架、阻断校验和 TXT 正文编译。
- `src/App.tsx`、`src/store.ts`：四栏工作台（原剧本、输入图片、导演板、H3 成品与质检）、浏览器草稿恢复、人工确认、全书阻断清单与全部分集生成。
- `electron/`：受隔离的桌面窗口、类型化文件对话框和原子写入。
- `tests/unit/`、`tests/e2e/`：引擎与界面流程验证。
- `99_过程归档/2026-09-28_阶段一闭环实施记录.md`：本次来源、实施范围、验证及剩余边界。
- `src/core/word.ts`：Word 剧本正文读取与通过质检后的 14 字段分镜导出。
- `src/core/images.ts`、`src/core/vision.ts`、`electron/vision.ts`：参考图片压缩预览、SHA-256 和可配置视觉模型描述。
- `99_过程归档/2026-09-28_Word与参考图描述实施记录.md`：本轮变更、验证和存储边界。
- `99_过程归档/2026-09-30_9.30升级实施记录.md`：v1.1 升级的实施范围、逐阶段改动、验证结果与剩余边界。
- `electron/menu.ts`：应用菜单正本。纯中文标签 + Electron 内置 role，功能零改动。
- `99_过程归档/2026-09-30_界面中文化实施记录.md`：界面全中文的盘点结论、改动范围、验证证据与剩余边界。
- `99_过程归档/2026-09-30_输入图片与分镜正文分区实施记录.md`：输入图片独立面板、正文编辑区隔离及验证依据。
- `99_过程归档/2026-09-30_导演意图自动生成实施记录.md`：导演意图由原剧本节拍自动生成的实施与验证依据。

- `99_过程归档/2026-09-30_台词内心OS旁白识别修复记录.md`：识别并保留对白、内心 OS、旁白类型及原文校验的实施记录；修复括号式内心 OS 闭括号污染分镜正文。
- `99_过程归档/2026-09-30_无依据动作与微表情修复记录.md`：无原稿依据时，肢体动作与微表情统一填“无”，并保留回归测试与构建证据。
- `99_过程归档/2026-10-01_台词内心戏与导入编码修复记录.md`：⑫ 只读原稿且无内容填“无”；TXT/Markdown 导入支持 UTF-8、UTF-16 BOM 与 GB18030 回退。
- `99_过程归档/2026-10-01_Markdown说明文档误生成分镜修复记录.md`：识别方案/模板说明文档，阻止其被误当剧本生成大量分镜。
- `99_过程归档/2026-10-01_加粗元数据误入台词修复记录.md`：过滤 `**字段：**` 元数据，避免其进入分镜⑫。
- `99_过程归档/2026-10-01_微动作微表情证据收敛修复记录.md`：动作与微表情只在原稿有证据时回填，写入边界二次拦截凭空补写。
- `99_过程归档/2026-10-01_正文识别与证据型生成修复记录.md`：非正文块（来源 / 人物设定 / 故事梗概）不进分镜；④构图 ⑧肢体动作 ⑬音效 改为证据型生成并与站位同源；人物识别落到真实姓名。
- `99_过程归档/2026-10-01_导入载荷分流与乱码修复记录.md`：导入按内容魔数分流（伪装成 `.txt` 的 docx 交给 Word 读取器）、无 BOM UTF-16 识别与二进制载荷拦截的实施与验证依据。
- `99_过程归档/2026-10-01_站位姓名与剧情设计生成修复记录.md`：⑦ 站位只写真实人物姓名（名册 467→109 条纯角色词、非人名命中归零）；⑧⑨ 由「无证据填无」改为「情绪档 + 跨集人物弧光」剧情设计，仅空镜填「无」；分集 167→60 段、集号无跳号的实施与验证依据。
- `99_过程归档/2026-10-01_音效空间底噪与孤儿模块清理记录.md`：⑬ 音效由「严格取证」改为「声源证据 ＋ 场景空间底噪」，真稿含底噪 90.7%；孤儿模块 `src/core/text.js`、`shared/text.js` 备份后清理，`electron/text.ts` 确认为导入唯一正本。
- `electron/text.ts`：导入载荷分流与解码正本（**唯一正本**，`src/core/text.js` 与 `shared/text.js` 两份失效副本已清理）。`sniffScriptPayload` 按魔数判定 docx / 文本；`decodeScriptBytes` 依次处理 BOM、无 BOM UTF-16、严格 UTF-8 与 GB18030 回退，并对解码结果做二进制体检。

运行：`npm install` 后 `npm run dev:desktop`；浏览器预览可运行 `npm run dev`。`npm run verify` 执行文档、单元、构建和界面测试。浏览器草稿存于当前浏览器本地存储，正式留存请使用“保存项目”导出 JSON 快照。
