# 本地图片自动描述升级记录

## 目标

在不调用 AI、不联网的情况下，导入参考图后立即得到一段可编辑描述，并允许对已有图片单张或批量补齐描述。

## 实施

- `src/core/analyze.ts` 的 `buildLocalDescription` 收敛为只输出文件名与像素主色卡，避免冗余推断文字。
- 文件名描述去除扩展名；图片区增加“清空描述”，仅清除当前集文字并保留图片与分析结果。
- 色卡升级为最多 8 个代表色，按细分桶内实际均值输出；透明像素与低于 1.5% 的小色桶过滤，分析采样边长提升到 1024px，并在图片卡片显示色块。
- `src/App.tsx` 导入图片时采样并自动写入本地描述；新增“本地生成描述”和“补齐本地描述”。批量操作只处理空描述，不覆盖人工内容。
- AI 描述入口保留为可选增强；本地描述仍需人工核对并确认，未确认不改变导出闸门。
- `tests/unit/workbench.test.ts` 增加描述模板回归测试。

## 验证与回滚

- 运行 `npm test`、`npm run build`、`npm run test:e2e`。
- 本次改动由独立 Git 提交记录，可按提交回滚。
