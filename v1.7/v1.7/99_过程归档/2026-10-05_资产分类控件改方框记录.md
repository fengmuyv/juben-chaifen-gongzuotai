# 2026-10-05 资产分类控件改为方框（样式统一）记录

## 一、老大反馈

> 现在把（截图：资产面板「人物 ·…」那一处）跟其他按键一样做一个文本框的形式

截图指向资产面板顶部的**分类切换控件**（`显示当前类别 + 张数 + 有描述数 + 折叠箭头` 的那一条）。

## 二、问题（改前）

该控件是 `.asset-kind-trigger`，样式为「**透明无边框**」：

```css
.asset-kind-trigger { … padding: 2px 0; background: none; border: 0; border-radius: 3px; … }
```

而它所在的容器 `.asset-group-head` 自带浅灰绿底 + 边框，同行右侧的「导入」按钮又是「白底 + 边框」的标准按钮 —— 结果是**同一行里三种形态**：容器一块底色，分类是无框标题，导入是方框按钮。视觉上分类控件不像一个可点的控件。

## 三、改法（只动样式，一行结构未改）

`src/styles.css`：

1. `.asset-kind-trigger` → **白底 + 同款边框圆角 + 内边距**，与面板内其余按键一致：
   - `padding: 5px 9px`（与相邻「导入」按钮同档）；
   - `background: #fff`；`border: 1px solid #cdd6d3`；`border-radius: 5px`；
   - 追加 `:hover`（边框加深）与 `:focus-visible`（绿色描边 + 光晕，与全局输入控件同款）；
   - 箭头 `svg` 改 `margin-left: auto; flex: none` 贴右 —— **不用 `space-between`**，否则「人物 / 2 张 · 有描述 2 / ⌄」会被均分拉开，张数信息会飘到中间。
2. `.asset-group-head` → **去掉自带底色与边框**（`background` / `border` / `padding` 全撤，改 `margin: 6px 0 2px`），否则会「框套框」（外面一圈容器框，里面再一圈控件框）。
3. 「导入」按钮 padding 由 `4px 8px` → `5px 9px`，与被改后的分类框对齐。

`.asset-kind-menu`（弹出小框）**未动** —— 定位基准仍是 `.asset-group-head`（`position: relative` 保留），展开方向与层级不变。
