## 1. P1 的准确范围（一处主动收窄，理由在代码里）

方案 §7 原话是「把 `rules.ts` / `director.ts` / `script.ts` 的硬编码抽成内置默认包」。落地时发现 **`script.ts` 在本期做不到**：

- `tsconfig.electron.json` 是 `rootDir: "electron"` + `include: ["electron"]` → 主进程**无法 import `src/` 下的任何文件**（引进来会破坏输出目录结构、被 TS 拒绝）。
- 主进程侧判据改由**运行时读盘**（`resources/skills/**/rules.json`）解决 —— 那正是 P2 的 `SkillManager`。
- 方案 §4.3 自己写的就是「**加载器就位后**两侧都从 skill 包读，双写与那条护栏断言同步退役」。

**故本期只做渲染层**：`rules.ts` / `skeleton.ts` / `director.ts` 三处收拢。`electron/script.ts` 的双写**保留**，其一致性断言（`workbench.test.ts`「AI 侧禁词与本地闸门逐词一致」）**不退役** —— 退役动作归 P2/P3。

## 3. 「单源」怎么落实的（不是复制一份）

`rules.ts` / `skeleton.ts` 改为**再导出**默认包的同一引用，**导出名与签名一字不改** —— 因此所有既有 import 路径（`validator` / `audit` / `director` / `App.tsx` 等）**一行未动**。单测直接以 `toBe`（引用相等）锁死这一点：

```
expect(rulesForbiddenWords).toBe(transitionForbiddenWords)
expect(fields).toBe(skeletonFields)
expect(generatedKeys).toBe(skeletonGeneratedKeys)
```

`director.ts` 的 11 条 `transitionRules` 改为按**具名 key**（`transitionTemplates.actionMatch` 等）取值，而不是按下标 —— 避免以后在池中间插一条就整体错位。

## 4. 验收：逐词比对怎么做的（关键纪律）

新增 `tests/unit/skill-default.test.ts`（15 项）。**期望值一律以字面量写在用例里**，不从默认包读出来再与默认包自己比 —— 那样搬运时抄错一个词，断言会跟着一起错、永远保持绿色。

覆盖：
- 禁词 27 条**逐词逐序**；正则源串 == 词表 `join('|')`；「缓慢推近 / 横向移动跟随」不误伤、「单纯推 / 叠化 / 闪黑」命中；
- 短名池 11 条逐词逐序；成稿池 11 条**逐字**、无重复、与短名池一一对应；
- 14 格 key 顺序 + label 逐字；11 键 + 3 键无交集且合计 14；
- 闸门表 40 条**逐条** `severity` / `category`；`error` 必属事实类或内容安全；
- 三个模块的导出**与默认包同引用**（`toBe`）。
