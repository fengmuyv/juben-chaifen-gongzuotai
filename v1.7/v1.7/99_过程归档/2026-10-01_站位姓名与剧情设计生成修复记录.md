# 站位姓名与剧情设计生成修复记录

## 老大反馈（2026-10-01）

1. **人物站位和朝向不能用代称**，要用相应的人物的名称。
2. **微表情和微动作怎么所有都是「无」** —— 这个是根据剧情设计出来的，不是凭空想象。

裁定口径：微表情依据范围 = **含跨集人物弧光**（在剧情语义之上再引入角色弧光与首尾呼应，自由度最高，人工复核量最大）。分集与生成同属一条根因链，本轮**一起修**。

## 实测取证（修复前）

用真实整本剧稿（60 集）跑本地规则导演，实际产出：

| 症状 | 实测证据 |
|---|---|
| ⑦ 站位混入非人物词 | `左侧播放时长与右侧名场面`、`左侧刀尖与右侧冯京`、`军刀和刀尖和小女孩`、`他自己和自己`、`有人位于 …` |
| ⑧⑨ 大面积「无」 | ⑨ 微表情约 99% 为「无」，⑧ 肢体动作同样普遍为空 |
| 分集错乱 | 60 集被切成 **167** 段（跳号 58 处），首集吞封面，第 2 集 0 节拍 |
| 名册污染 | 人物名册被元数据、部位词、数量副词混入，膨胀到 **467** 条 |

## 根因

1. **名册污染 → 站位代称**：`projectCast` 只按说话人与叙述句主语粗提姓名，未剔除元数据标题（`播放时长` `名场面` 等）、部位词（`刀尖` `脚步` `指尖`）与数量副词（`一步一步`），导致这些词被当作人物写进 ⑦ 站位。
2. **生成口径倒挂**：`director.ts` 只在原稿存在可观察证据时才写 ⑧⑨，无证据一律填「无」—— 把「依据不足」等同于「剧情无动作」，与老大「根据剧情设计」的口径相反。
3. **分集切点误判**：集头导语（`第 2 集：扫荡戏开拍。…`）与附录索引行（`EP31—EP60`）被误当集标，且同集号 `byNumber.set` 取最后一个，覆盖真集标。

## 口径（本轮新增，改代码前必看）

- ⑦ 站位与朝向**只写真实人物姓名**，部位词 / 数量副词 / 元数据词一律不得登记为人物。
- ⑧ 肢体动作、⑨ 微表情：**原稿有证据优先取证**；无证据时按「情绪档 + 跨集人物弧光强度档」**设计**，不再一律填「无」。
- 仍填「无」的唯一情况：**空镜**（画面只有环境或声音、无人物入画）。
- 微表情一律禁止情绪形容词（`紧张 / 愤怒 / 悲伤 / 开心 / 害怕 / 惊讶 / 无奈 / 尴尬` 等），只写肌群级与肢体级可执行动作。
- 分集切点单一来源 = `episodeHeadingOf`；`episodes.ts` 不得另写正则。
