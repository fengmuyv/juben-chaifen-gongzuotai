# 说话人命名与场次轴线锚修复记录

## 老大反馈（2026-10-01 · 五次）

1. 「**谁说话就用谁的名字**。」
2. 追问澄清：「**两个都要，因为说话涉及微表情和微动作**」——⑨ 站位主体与 ⑫ 台词都要落到说话人姓名；
   说话人要承载 ⑩ 肢体动作与 ⑪ 微表情。
3. 注解写法裁定：「**⑨ 只写名字，⑫ 保留原文**」。
4. **关键纠正**：「**不是谁说话谁就站左，是根据上下设计的人物站位，这个不能乱跳，不然就穿帮。**」
   —— 左右由场次上下文设计的站位（轴线）锁定，逐镜不许跳；说话人只保证**名字出现**，不决定左右。
   此条**取代**此前「按原稿出现先后」的口头选项。

## 根因（两类，均为「生成本文 × 剧本」错位）

1. **名册被叙述片段污染（P0-1）**。名册的第三条发现通道「叙述句主语」把「动词之前 1~4 字」当姓名，
   真稿上产出 35 条，其中**仅 3 条是人物**（`小女孩` / `鬼子兵` / `老人`），其余 32 条是副词
   （`慢慢` / `缓缓` / `突然` / `同时` / `直接` / `亲自` / `同一` / `上午`）、器物
   （`椅子` / `瓶子` / `机器` / `秒针` / `皮鞋` / `进度条` / `板子` / `救护车`）、
   谓词片段（`用凉水` / `直到它` / `当投名状` / `说完他` / `让她` / `朝林昊` / `往回` / `往门口` / `标好` / `出租车开` / `桌上并排`）
   与姓名近似形（`冯京一` / `林昊正` / `刘杨正` / `江天往` / `楚忠重新`）。
   而 ⑨站位 / ④构图只写名册里的人 —— 于是站位写出「左侧冯京与右侧冯京一」「左侧冯京与右侧慢慢」这类穿帮主体。
   **频次阈值不可用**：`同一` 出现 68 次、`椅子` 31 次、`慢慢` 28 次，全是噪声。
2. **侧位按「本镜前两名」相对取左右（P0-2）**。双人分支取 `ordered[0]`/`ordered[1]` 分列左右，
   而 `ordered` 只含**本镜入画的人** —— 同一人物单独入画时在右，与锚内靠前者同框时就被推到左，
   第三人一入画即翻转，同场次内反复跳变（真稿 110 处），即老大说的「乱跳 → 越轴穿帮」。

## 实施

### 名册收口（`src/core/parser.ts` + `src/platforms/minimax-h3/director.ts`）

- **唯一发现通道**：`projectCast()` 的名册正本＝人物设定块姓名 ＋ 可信台词说话人（`parseScript().cast`），
  真稿 62 条全部干净。
- **叙述句主语降级为佐证通道**：`narrationSubjects()` 仍抽取「动词之前的姓名位」，
  但只在命中两类时补登记 ——
  ① 已是确证姓名（用于登记其在原文的出现次序）；② 命中**单一来源**角色称谓表 `roleSpeaker`
  （`parser.ts` 导出，与 `speakerTrusted` 共用同一张表，补入 `女孩` / `男孩` / `孩子` / `老头` / `老太太` / `兵`）。
  其余一律视为叙述片段噪声，不进名册。
- **代价与逃生口（已登记）**：只以叙述出场、从不说话、也不在设定块里的**专名**将不再自动入册；
  需在人物设定块登记或给一句台词。真稿 62 条已覆盖全部发言主体，未触发该边界。

### 场次轴线锚（`src/platforms/minimax-h3/director.ts`）

- 新增 `sceneAnchorOf(project, cast, episode, sceneId)`：**单一来源**的场次轴线锚 ——
  取本场次全部节拍文本 ＋ 可信说话人裸名，名册命中者按**原稿出场次序**排定，整场锁死；
  缓存键含 `project.id`（防跨项目 `ep-01|scene-1` 撞车）。
- 新增 `shotSpeakers(episode, shot)`：**谁说话就用谁的名字** —— 本镜 `kind === 'dialogue'` 的可信说话人
  （`speakerNameOf` 剥掉 `（画外音）` 类舞台注解）一律进主体，不受名册「≤5 字 / 不含字母数字」判据限制
  （`评委A` / `投资方代表甲` 照样写得出）；`inner` / `narration` 不计入。
- `stagingFor(subjects, inherited, anchor)`：`sideOf` 改为**纯函数** —— 只由「（场次锚 + 人物名）→ 左/右」
  决定（锚序 0 左、1 右、2 左……交替），**与本镜还有谁入画无关**，因此任何镜头组合下同一人物侧位恒等。
  分列写法改为按**绝对侧位分组**：两侧都有人时写「左侧〈左组〉与右侧〈右组〉分列画面左右三分之一」，
  同侧多人仍逐个写出姓名与朝向，位置不因他人在场而改变。旧的「emotion→画面中央 / establish→右」分支删除。

## 口径裁定点（待老大复核）

1. **叙述句主语只佐证、不发现** —— 这是本轮的**口径收紧**，取代此前的「姓名取自人物设定块 ＋ 台词说话人 ＋ 叙述句主语」。
2. **轴线的左右规则**：出场次序 0 在左，其余按 0/1/2/3… **左右交替**；同侧多人逐个写名。
3. **⑨ 只写裸名，⑫ 保留原稿原文**（零篡改）。

## 剩余边界

- 只以叙述出场且从不说话的**专名**不再自动入册（见「代价与逃生口」）。
- 同一场次 3 人以上时，左右按出场次序交替；被分到同一侧的两人按同侧写法并列，不强行拉成对视正反打。
- 字段编号在各文件注释/历史归档中的旧写法（`⑦站位` / `⑧肢体动作` / `⑨微表情`）与产品方案正本
  （⑦光源 ⑧氛围 ⑨站位 ⑩肢体动作 ⑪微表情）仍不一致，属**已登记漂移**，统一扫尾待老大批准。
