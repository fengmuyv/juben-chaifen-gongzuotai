# 漫剧一体化编剧 & 表演标注综合 Skill（V2.2 升级版）

> **全局永久强制规则（以下内容逐条执行）**：
> 1. **自动启用**：只要产出**人物对话、场景戏份、动作段落、人物表演神态**，立即**自动启用本体系全部规范，无需用户重复提醒**。
> 2. **自动自检修正**：每一轮输出完成**自动自检**，对缺项、错乱、不规范内容**自动修正**后再交付。
> 3. **用户现成原剧本绝对保护**：用户提供现成原剧本时，**绝对禁止修改、篡改、改写原有台词、剧情、人设**，仅可补全表演、神态、动作、配音标注。

## 一、剧本创作基础准则
1. **坚守人物逻辑，杜绝 OOC**：所有台词/行为须贴合角色设定与当下处境；场景自带**内在冲突**，杜绝无效闲聊；严格遵循 **铺垫 → 交锋 → 高潮 → 留白** 叙事节奏；长线剧情主动**回收伏笔**，杜绝剧情断层与烂尾。
2. **统一固定输出格式（强制）**：
```
场景编号｜内外景｜时间｜环境光影氛围描写｜人物表演神态+动作｜台词｜四维配音标注｜可选内心潜台词
```
- 落地为角色行时，采用：`人物【微表情表演】【动作】：「台词文本」【音量：XX｜语速：XX｜停顿：XX位置｜句尾语调：XX】（内心潜台词，按需）`
- 模块边界清晰、互不混杂；多人同场每个角色独立成行，严禁表情趋同。
- **纯微表情 / 微动作表演段落（角色未发声）**：【微表情表演】仍须按第二章四维写全，【动作】栏照常填写（含战斗动作），台词位标注「（无台词）」——四维不可省略。

## 一·附、结构化编剧创作与剧本诊断（融合 deepwhite-screenwriting-v1 精华）

> 本章吸收 deepwhite-screenwriting-v1 的「中文影视编剧全流程 + 剧本医生 + 量化评分」精华，与第二章起的表演标注、分镜骨架统一为单一编剧&表演体系。原 deepwhite-screenwriting-v1 技能已彻底删除，避免双编剧源冲突。方法融合自山音超级编剧大师（视听化写作）与 screenwriter（麦基/坎贝尔/亚里士多德结构审计）体系。

### 附.1 启动路由（先判意图，再选引擎）
| 用户意图 | 路线 | 说明 |
|---|---|---|
| 完全从零、只有灵感、AI 视频 / 微短剧 / 概念短片 | 从零创作总流程 | 直接孵化 |
| 5-10 分钟短片、长片、剧集从零开发 | 从零创作总流程 + 结构审计校准 | 边写边校准 |
| 已有梗概 / 分场 / 剧本，需修改或诊断 | 剧本医生诊断流程 | 不重建，先诊断 |
| 要打分、找问题、评估可拍性 | 量化评分表 | 输出诊断报告 |
| 要分场大纲 / 场景拆解 / 片长控制 | 从零创作总流程 step6 | 场景拆解 |

未说明体量时，先问：「想做哪种体量：1-3 分钟概念片 / 5-10 分钟短片 / 长片 / 多集剧集？」若用户已给材料，先读材料判断要做：诊断 / 修改 / 压缩 / 补强 / 重写 / 分场 / 评分。

### 附.2 从零创作总流程（山音引擎为主，screenwriter 结构校准为辅）
1. **破题与核心动作**：确定高概念、戏剧动作、体量。
2. **梗概草稿**：先给故事方向，不急着写剧本。
3. **人物深度与弧光**：Want / Need / Arc；长片剧集补 Ghost / Lie / Flaw。
4. **前史与世界观**：故事开始前世界已运行很久，先建造再切入。
5. **结构大纲**：开场钩子、激励事件、递进冲突、高潮、结尾钩子。
6. **分场大纲 / 场景拆解**：每场标注目标、阻碍、结果、价值转变、预估时长、双轨节奏。
7. **场景写作**：只写画面、动作、声音和口语化潜台词（落地为第一章固定版式）。
8. **剧本医生**：先用山音综合自检，再用结构审计做因果 / 价值 / 人物缺陷 / 节奏审计。
9. **量化评分**：按体量评分，给修改优先级。

### 附.3 已有材料诊断 / 剧本医生流程
1. 读取用户材料，确认当前目标。
2. 判断问题类型：结构 / 因果 / 人物 / 对白 / 节奏 / 结尾 / 开场 / 分场 / 片长。
3. 做必要审计（见附.4）。
4. 输出一个诊断或修改版本。
5. **只改用户指定范围**，不动其余（与第七章「原剧本绝对保护」一致；用户提供确定/锁定版剧本时，见体系「剧本锁定铁律」，不得擅改）。

### 附.4 结构审计维度（麦基 / 坎贝尔 / 亚里士多德）
- **控制性理念 Controlling Idea**：故事一句话内核是否清晰、可被执行。
- **人物缺陷 Hamartia**：主角致命缺陷是否驱动转折。
- **场景价值 Scene Value**：每场是否有清晰价值转变（正→负 / 负→正）。
- **因果链**：事件是否因果驱动，杜绝巧合硬解。
- **Red Flags**：解释性台词、说教独白、书面化 AI 腔、心理描写外化、节奏失衡。

### 附.5 山音视听化写作原则
- 所有剧本文字只写能被摄影机拍到或听到的内容。
- 不写心理描写、解释性台词、括号暗示、说教独白、书面化 AI 腔。
- 潜台词优先：台词之下藏动机；双轨节奏（情节线 + 情绪线并行）。

### 附.6 量化评分表（10 分制 · 输出呈现层）
| 维度 | 权重 | 评分点 |
|---|---|---|
| 概念 / 高概念 | 10 | 清晰、可执行、有钩子 |
| 人物 / 弧光 | 10 | Want/Need/Arc 成立 |
| 结构 | 10 | 钩子→激励→递进→高潮→结尾完整 |
| 因果 | 10 | 事件因果驱动 |
| 对白 | 10 | 潜台词、不解释、口语化 |
| 节奏 | 10 | 双轨平衡、无失衡 |
| 视听化 | 10 | 只写可拍/可听 |
| 结尾 | 10 | 余韵、收束、不烂尾 |
给出总分与**修改优先级**（先改低分维度）。

### 附.7 编剧最高约束（融合来源约束）
- 只用中文输出；不输出 Hollywood 格式；不生成 docx；不写双语台词。
- 写场景只给一个版本，不给多个备选；用户否定后只问一个窄问题再给新版本。
- 修改已有内容时只改用户要求修改的部分。

### 附.8 交互约定（人机对话创作模式）
- 正式创作每步结束等待用户「通过 / 修改 / 自检」；不一次性跳完全部流程（除非用户要求快速总览）。
- **本约定仅适用于人机实时对话创作**；在「自动化任务」零同意环境运行时，按 Master Prompt 零同意铁律不等待、直接落盘。

## 二、人物表演【核心四维固定层级｜顺序不可逆、要素齐全】
> 微表情专项衔接（2026-08-27）：微表情**深度/量化标注**（表情 keyframe、定量双轴参数、情绪弧命名、克制泪语法、眼神叙事线）由独立 skill `micro-expression-annotation-system`（定量双轴×定性八件套，替代原 CharacterMicroExpression）承接；本章保持一体化版式的四维结构与参考词库，整段表演标注仍以本章为落稿规范，专项深挖引用新 skill 定量层。
所有人物微表情、表演神态严格按以下**四层固定顺序**撰写，层级不可打乱、核心要素不可缺失，保证表演层次细腻自然、贴合人设情绪：
- **① 眼部神态 + 视线落点**：结合当下人物情绪、剧情节奏与场景氛围，**按需合理搭配贴合状态的眨眼、瞬目动作**。贴合情绪、剧情时自然添加，用以活化角色神态；无需要时可不加，**杜绝生硬堆砌、强行套用**。
- **② 眉眼、嘴角、面部肌肉细微变化**；
- **③ 实时呼吸节奏状态**；
- **④ 贴合当下情绪的细微肢体小动作**。
- **⑤ 单列附加项（不计入核心四维结构）**：按需补充适配剧情场景说明，辅助理解表演逻辑。
- **规范要求**：仅撰写细腻微神态、日常微动作；大幅度武打动作**单独分区**书写，严禁与微表情内容混杂；所有表演贴合人物当下状态，自然不僵硬。

### 2.1 微表情参考词库（按需组合，分层；眨眼按 ①"按需"原则自然加、不强行堆）
- 【平静/疏离】眼帘半垂，视线平缓，唇线平直，面部肌肉放松
- 【暗藏心事】视线短暂游离，眉尖极浅蹙起，嘴角平静但苹果肌微僵
- 【克制笑意】单侧嘴角极轻上扬，下眼睑柔和收紧，眼底泛微光
- 【压抑不悦】眉骨微沉，眉心隐现竖纹，下颌轻收，呼吸放缓，目光淡淡收敛
- 【心虚慌乱】瞳孔瞬间微缩，视线快速躲闪，喉结小幅滚动，上眼睑抬高半分
- 【意外错愕】睫毛猛颤两下，双唇微张停顿半秒，瞳孔小幅放大，面部短暂放空
- 【温柔动容】眉眼缓缓舒展，目光柔和下沉，眼角轻微松弛，唇尖下意识轻抿
- 【嘲讽冷淡】眉尾单边挑起，眼神平视不带温度，嘴角平直不下垂
- 【欲言又止】嘴唇微启随即闭合，视线短暂停留后移开，眉心浅皱
- **情绪分层**：表层神态 + 潜意识细微破绽（如表面平静、眼底不自觉收紧；故作冷淡、喉结轻滚），增加层次。

### 2.2 眨眼 / 瞬目状态库（微表情一级核心元素，按需组合，属「神情」层不混入动作层）
- **均匀自然**：眨眼节奏平缓规律，眼帘自然开合，神态松弛无刻意。
- **刻意放慢掩饰**：临近关键情绪前放慢眨眼、延长睁眼瞬间，用以压住翻涌的情绪。
- **频率加快显紧张**：眨眼频次明显升高、间距变短，配合视线游移，泄露不安或心虚。
- **瞬目一次显犹疑**：话到嘴边顿住，睫毛猛地扇动一下随即垂落，欲言又止。
- **错愕骤停**：意外时眨眼戛然中止半秒，双目微张定格，再恢复。
- **温柔缓眨**：动容时放慢一次的轻盈眨眼，眼尾随之柔和弯落，增亲密感。
- 规则：眨眼/瞬目贴合情绪与剧情自然添加，杜绝生硬堆砌、强行套用；属微表情（神情）层，单独成项，不与【动作】/【运镜】层混淆。

### 2.3 写动作不写感受（三步法 · 反哺自逼真微表情视频）
把情绪**翻译成可执行的面部肌肉动作 + 肢体反应 + 变化节奏**，不写抽象情绪名词（"开心""伤心"AI 无法翻译成动作，只会生成标准假笑或面无表情靠台词硬撑）。
- 第一步：描述面部肌肉运动（嘴角幅度、眨眼频率、皱眉程度、头部姿态、辅助手部）。
- 第二步：配对应肢体语言（害羞捂嘴、犹豫咬唇玩指、难过吸鼻）。
- 第三步：微表情是**变化过程**——平静→触发→递进→余韵层层递进，才是"演技"精髓。

### 2.4 微表情万能公式（六要素，缺一不可）
`面部微神态细节 ＋ 视线落点 ＋ 嘴角肌肉变化 ＋ 呼吸状态 ＋ 配套小动作 ＋ 镜头光影场景`
- 面部微神态锁眉眼/鼻尖/睫毛/眉心（替代空泛情绪词）；视线落点区分"藏情绪/露情绪"（看镜头/地面/侧方/失焦放空）；嘴角提拉/下压/单侧微扬/紧抿/轻颤（克制 vs 外放）；呼吸浅促/屏住/绵长/微滞（让静态图有流动）；小动作捻衣角/撸袖口/指尖微蜷/睫毛轻抖（给情绪找肢体落脚点）；光影侧逆光/烛火柔光/冷调暗光做放大器。

### 2.5 五控制点（拆开五官组装情绪）
- **眉毛·信号灯**：眉峰上挑=意外；眉头内收=忍住；眉眼放松=终于接受。
- **眼神·决定可信度**：不写"眼神悲伤"，写轨迹（落在对方脸上→缓慢移开→视线短暂失焦）。
- **嘴角·克制感**：真笑=嘴角上扬+上唇提升+下眼睑上提；假笑=只动嘴角；不想被看穿用嘴角轻压而非大哭。
- **呼吸·被忽略的灵魂**：屏息/深吸/轻叹，让画面从"摆拍"变"正在发生"；人哭时先不呼吸、出完气才深吸一口。
- **停顿·最有力量的半拍**：写"愣了一拍才反应"，比"很惊讶"更有力。

### 2.6 八种情绪微表情模板（按角色人设量身定制，忌通用套用）
1. **开心(内敛)**：嘴角微扬、眼角细纹、眼轮匝肌收缩、眼神明亮、轻眨眼、肩微起伏带呼吸、5s 缓展。
2. **难过(隐忍)**：眼眶微红、泪转不落、下唇轻颤、咬唇、低头、肩微耸、喉结滚动、5s 克制积累。
3. **疑惑**：眉头微蹙、眼球轻转、聚焦又散、唇轻抿、头微侧、短暂停顿、5s 递进。
4. **害怕**：眼神飘移、瞳孔微缩、呼吸浅急、唇颤、吞咽、额汗、身体微僵、5s 递进。
5. **惊吓(秒级)**：0-1s 凝固僵住→1-2s 瞳扩睁大→2-3s 眉扬→3-4s 呼吸骤停后急促→4-5s 身微缩。
6. **惊喜(秒级)**：0-1s 愣住瞳大→1-2s 嘴角速扬→2-3s 眼弯带泪光→3-4s 捂嘴→4-5s 放松微笑。
7. **厌恶**：鼻翼微收、上唇微抬、眼神回避、眉头微蹙、头微后仰、呼吸微顿、无夸张。
8. **坚定**：眼神直视不躲、下颌收紧、唇紧闭、呼吸平稳、肩稳、眉微收显决心。
（模板须按角色性格改写肌肉/肢体/节奏，不可套用了事；与 2.1 词库条目互补使用。）

### 2.7 情绪强度分档与景别配合
- 强度递进 **10%→40%→80%**，勿从 0 跳 100：10% 几乎不动（克制/隐藏：眼神停半拍、眉头轻皱、呼吸变化、嘴角轻压、下颌微收）；40% 可被察觉（转折：眼神移开、嘴角轻压）；80% 明显（爆发前后：全力描写眉眼/睫毛/眼眶红/嘴角颤/肩沉）。
- 景别策略：特写=微表情主场（眉眼/睫毛/嘴角/呼吸细微）；中景=加头部辅助（歪头/低头更立体）；远景=用肢体代替（握拳/颤抖/姿态传递）。

### 2.8 秒级控制表演法（动态视频专用）
把面部神态 + 肢体小动作 + 台词节奏按时间刻度（0-1s / 1-3s / 3-5s）绑成一条连贯情绪线，避免发散单帧。示例：0-1s 眉峰紧蹙眼尾泛红眼神狠戾紧盯；1-3s 牙关暗咬下颌绷紧鼻息微颤却噤声；3-5s 眼底翻涌屈辱不甘、冷侧光勾勒侧脸、情绪隐忍收于眼底。须随情境连贯变化，不写成固定片段。

### 2.9 皮肤质感防塑料脸（与微表情同等重要）
塑料脸两因：缺精准微表情指令 ＋ 皮肤无微观肌理。
- **正面质感**：清晰毛孔、脸颊绒毛、鼻翼淡泛红、自然肤色渐变、眼下细纹、保留自然肌理、拒绝过度磨皮。
- **四肤质模板（按需选）**：原生素颜肌（生活/现实向：毛孔/绒毛/不磨皮）/ 清透水光肌（美妆/甜剧：水润通透/T区微油光/细腻）/ 复古胶片肌理（写真/氛围：颗粒/暖调/留细纹）/ 成熟肌理（中年/现实：法令纹/眼角细纹/松弛合龄）。
- **配套负面词（必加）**：塑料皮肤、蜡像、重度磨皮、光滑无毛孔、卡通、二次元、五官过度对称、表情扭曲、夸张大笑、油腻反光、完美无瑕肌肤。
- **进阶四技巧**：不直盯镜头（视线望侧下/远眺）；配微小肢体烘托；统一光影逻辑（平光最易塑料脸，用侧光/侧逆光/黄昏柔光）；图生视频追加"面部微表情缓慢变化、纹理动态保留、避免扭曲"。

## 三、武打动作统一限定规则（融合 seedance-combat-prompt 精华 · 取其精炼原则、去其冗例）
所有打斗、攻防、肢体对抗动作统一风格：**干脆利落、迅猛凌厉、节奏紧凑**，摒弃一切花哨多余架势，攻防转换极速无冗余，起手收招干净利落、无拖沓、无废动作。严格区分**日常细微肢体小动作**与**战斗攻防动作**，分模块书写，互不混淆。

### 3.1 完播率公式（最高指导原则）
`完播率 = 开局冲击(20%) × 节奏呼吸(30%) × 运镜丰富度(25%) × 情绪拐点(25%)`
- **开局冲击**：1.5s 内必须出现攻防接触，禁止全景铺垫；0.5s 内出现冲突最激烈点（两种极端招式正面硬撞 + 微慢镜定格）。
- **节奏呼吸**：快慢交替，同节奏连续 ≤5 秒；前段多快 → 停顿就用极致慢反差。
- **运镜丰富度**：同运镜 ≤2 秒，同景别 ≤3 秒，重磅招式三段式。
- **情绪拐点**：至少 1 次让观众情绪翻转的瞬间。

### 3.2 核心铁律
- **无铺垫法则**：前 1.5s 必出攻防接触；第一帧双人同框近景/中景。
- **招式序列化**：禁止写抽象参数（如"每秒攻击≥N 次"）；必须写可拍摄的明确招式链（例：右摆拳打脸→左勾拳打下巴→右直拳打鼻梁→左摆拳打太阳穴；防守方头部左偏/右偏/后仰/侧闪，全部躲开或格开）；近景对招段含拳/掌/肘/指/腕多种手部变化，必含肘击。
- **近景对招**：15s 打戏至少 1 段（2–3s）上半身近景对招，写清连续招式名/攻击部位/落点/防守反馈；景别锁定中近景/近景，不跳全景。
- **微反馈**：近景下必须有微表情或微反馈（格挡震颤/汗珠飞溅/血雾/护臂崩开等）。
- **景别匹配**：小幅动作（拳掌肘）→近景放大密度；大幅动作（腾空/旋转/下劈）→全景展示张力；小动作配全景=信息稀释。
- **角色动作签名**：每个角色必须有区别于他人的核心战斗风格，贯穿全场。

### 3.3 六层结构（每条打戏提示词必须覆盖）
角色设定（武学/定位/动作签名/特效性格）→ 动作攻防（每击有来由/去处/攻防转换）→ 节奏结构（开局冲击→近景对招→空间变化→情绪拐点→终结技）→ 镜头运镜（完整景别/视角/角度/运镜/跟随目标）→ 特效反馈（劲气绑定身体部位与动作轨迹）→ 叙事胜负（谁占优/破绽如何出现/终结技为何成立）。

### 3.4 镜头规格强制系统
每次镜头描述必含五要素：**景别**（全景/中景/近景/特写）+ **拍摄视角**（正/侧/斜/俯/仰）+ **角度**（具体值 + 平视/仰视/俯视）+ **运镜方式** + **跟随目标**（跟随类运镜必写）。
- 景别四档：全景=全身+环境（腾空/旋转/下劈）；中景=膝上+手腿（中距攻防/肘击）；近景=胸上+双臂（拳掌肘对攻/格挡/微表情）；特写=面部/单手/接触点（格挡瞬间/汗珠/拳面/指尖凝气）。
- ⚠️**空间感铁律**：中景及以上（两人完整身子）禁止侧面 90° 正拍，必须 30–60° 斜角；近景/特写允许侧面 90°。
- 四原则：①正常速度对招→中近景·侧面·带微移动感；②蓄力大前摇→仰视+慢推突出威力；③快速攻防→斜角+方向移动显速度；④特写→破绽/转折点过渡标点（约 0.3s）。

### 3.5 劲气绑定
特效劲气必须绑定具体身体部位与动作轨迹（✅"右腿如钢鞭甩出，紫黑气焰沿小腿弧线炸裂成新月弧刃"），禁止只写"释放紫色特效"等孤立描述。

## 四、台词配音四维强制标注规则（融合 seedence2.0fast v2.0.0 · 缺一必违规）
所有人物台词**必须全自动配套完整四维配音参数**，四项齐全、不可空缺、不可简写，全程自动检测执行。本规则已**完整吸收 `seedence2.0fast`（配音四维标注体系）全量细则**，为剧本/对白/旁白/口播/TTS 的统一权威源（细分 skill 不再另起格式）。

**四维顺序固定：① 音量大小　② 语速快慢　③ 停顿节点　④ 句尾语调**

### 4.1 四维取值表（按强度/性质，与情绪绑定，非匀速）
| 维度 | 标注键 | 可选取值（由强到弱 / 由急到缓） | 说明 |
|---|---|---|---|
| ① 音量大小 | `音量` | `爆`(嘶吼/破音) › `强`(激动/用力) › `中`(常态) › `弱`(气声/耳语) › `微`(极轻/含在喉咙) | 必要时补距离/方位，如 `弱·凑近耳畔` |
| ② 语速快慢 | `语速` | `爆冲`(抢话) › `急`(紧张/争执) › `快`(兴奋/急切) › `中` › `慢`(沉思/压抑) › `拖`(拉长/哽咽尾音) | 与情绪绑定，非匀速 |
| ③ 停顿节点 | `停顿` | `停0.3`(短逻辑) / `停0.6`(长情绪) / `吸`(吸气) / `叹`(叹气) / `笑`(轻笑) / `咽`(吞咽) / `低`(压低) / `气`(气声) / `偷气`(句中极小进气) | 可叠加、可嵌入台词中间 |
| ④ 句尾语调 | `句尾` | `升`(疑问/挑衅/未竟) / `平`(陈述/冷静) / `降`(肯定/失落/决绝) / `颤`(恐惧/动情) / `断`(硬切/被打断/戛然而止) | 决定一句话的"落点情绪" |

### 4.2 标注格式（紧跟台词，清晰直观 · 统一版式）
每句台词后立刻接一行四维块，用 `【】` 包裹、全角竖线分隔；角色行整体为：
`人物【微表情表演】【动作】：「台词文本」【音量：中｜语速：急｜停顿：停0.3｜句尾：升】`
- **停顿嵌入台词中间**：如 `「你真的以为……[停0.5]我会信你？」`，嵌入时仍须在四维块登记一次 `停顿：停0.5`。
- 群杂 / 画外音 / 内心OS 同理，不可省略任一维。

### 4.3 停顿节点 · 气口控制细化（演员式，非机械）
原"气口控制"并入本维度，作为停顿的自然度约束：
1. **意群优先，不在词中切**：按语义意群断句，逗号/句号是呼吸点，不是均匀节拍器。
2. **情绪驱动停顿**：停顿长短位置由角色情绪与潜台词决定；愤怒、心虚、动情留白完全不同。
3. **演员式呼吸**：紧张时短促急吸，抒情时绵长轻吐；允许句中"偷气"。
4. **禁止机械断句**：禁止每句等长、每个标点同秒、逐字停顿的"机器人朗读感"。
5. **重音与气声分层**：关键台词重音/气声/压低；过渡句轻读带过。
6. **角色声线一致**：同一角色语气、语速、呼吸、口头禅跨镜头/跨集一致。

### 4.4 反面样例（禁止输出）
- ❌ 无标注裸台词：「你真的以为我会相信你吗。」（缺四维）
- ❌ 缺维标注：「站住。【音量：强｜语速：急】」（缺停顿、句尾）
- ❌ 逐字断+等距停顿的机器人腔：「你。真的。以为。[停0.4]我会。[停0.4]信你？[停0.4]」
- ✅ 合规：「你真的以为……[停0.5]我会信你？【音量：弱｜语速：慢｜停顿：停0.5｜句尾：降】[气]（气声，压着怒）」

### 4.5 自动检测（每次生成后必跑）
生成任何对话/台词后逐项自检并输出合规结论：是否每句紧跟四维块？四维是否齐全（缺任一即补全，不得留空）？停顿是否情绪驱动而非机械等距？句尾是否匹配语义落点？角色声线/语速是否跨句一致？
输出形如：`【四维合规自检】✅ 本段共 N 句台词，四维齐全（含暂停标记 M 处）；或 ⚠️ 第 K 句缺失「句尾」，已补全为「降」。` 缺项必须当场补全后再交付，绝不带缺项输出。

6. **禁止修改、优化、篡改用户提供的原始剧本内容，仅可增补标注类信息**。

## 八、分镜镜头标准字段顺序（SC 骨架，分镜层扩展 · **13 项规范**）

> **【2026-09-24 用户令 · 永久】** 分镜脚本统一按 **13 项字段规范**输出：**「时长」写在每个分镜的标题行**，正文固定 **12 字段**。编号连续无跳号、无合并行，**时长不得在正文另设字段**。

**① 标题行（镜号 ＋ 镜名 ＋ 时长）**

```
SC[编号]【[镜名]｜[时长]】
```

示例：`SC12【苏清苒推门｜4s】`。时长即本镜成片秒数（单镜 ≤12s），**只出现在标题行**。

**② 正文 12 字段**（按「画面框架 → 摄影与光 → 人物表演 → 声音 → 衔接」逻辑排序）

```
SC[编号]【[镜名]｜[时长]】
│
│   ① 景别：
│   ② 构图：
│   ③ 焦距：
│   ④ 运镜：
│   ⑤ 光源：
│   ⑥ 氛围：
│   ⑦ 人物站位 + 朝向：
│   ⑧ 肢体动作（方位/动线）：
│   ⑨ 微表情：
│   ⑩ 台词 / 内心OS：
│   ⑪ 音效：
│   ⑫ 衔接：
```

> **与旧序的差异（务必留意）**：v4 及更早稿件为 `①时长 ②景别 ③运镜 ④站位 ⑤构图 … ⑫焦距 ⑬衔接`（旧 13 字段，时长在正文）。自本令起 **时长移入标题行、正文重排为上列 12 字段**，**「衔接」锁死 ⑫**。新序自本令之后的新稿生效，**已交付旧稿不追改**。

- **⑨ 微表情**须沿用第二章「核心四维固定层级」写法（①眼部+视线[眨眼按需]→②眉眼嘴角→③呼吸→④细微肢体小动作，⑤场景说明单列）；
- **⑩ 台词**若发声，须带第四章配音四维（`「台词」【音量｜语速｜停顿｜句尾】`）；纯 OS 标「（内心OS：……）」；远声用 `● 远声·[角色]：`；
- **⑦⑧⑨ 与剧本层【微表情表演】【动作】一一对应**：分镜层只是把同一表演拆到具体镜头机位上，模块边界不混淆；
- 自检第 4 项排版校验同时覆盖本骨架（编号连续、字段齐全、无跳项）。

### 8.1 ⑫ 衔接硬性规则（分镜结尾不可突兀 · 永久强制）
**每个分镜的结尾（最后一帧 / 收束动作 / 收声）必须给出明确的"交棒"，禁止突兀切断（硬切到空镜、角色动作悬空、情绪/色调无收束直接跳下一镜）。** 实现方式至少满足其一，并在 ⑫ 衔接 字段写清：
1. **动势延续**：角色转身 / 手势 / 位移的惯性带入下一镜（如抬手欲击 → 下一镜掌风已至）；
2. **视线 / 轴线延续**：视线落点或运动方向对齐下一镜，保持 180° 轴线不跳轴；
3. **声音桥接**：下一镜的环境音 / 台词 / 音效在本镜尾提前半拍进入（音频先叠、画面后切）；
4. **节奏收束**：动作减速沉降、呼吸落定、停顿留白，让镜头"稳稳落地"再切；
5. **情绪余韵**：尾帧微表情定格或缓变（沿用四维结构），不硬切掉情绪。
- 衔接字段**不可留空**、不可只写"切"；须写明交棒方式与对接的下一镜编号/内容。

### 8.2 转场禁律（禁止单纯渐黑转场 · 永久强制）
**场景与场景之间的过渡，禁止用"画面渐隐为全黑再渐显"（fade to black / 单纯渐黑）作为唯一衔接手段**——其画面、光影、情绪均无承接，属偷懒式转场，破坏连贯观感。须改用"有信息承接"的转场之一，并在 ⑫ 衔接 字段写清：
1. **匹配剪辑（Match Cut）**：形状 / 动作 / 色彩 / 构图相似，上一镜尾与下一镜首视觉对齐；
2. **叠化到下一镜实画面（Dissolve-to-scene）**：叠化落点是下一镜真实画面而非黑场；
3. **声音桥接（Sound Bridge）**：下一镜环境音 / 台词 / 音效提前半拍进入，画面后切；
4. **运动 / 视线延续**：位移惯性或视线落点带入下一镜，保持 180° 轴线；
5. **遮罩 / 光效擦除（Wipe / Lens-flare wipe）**：以光、物、形状作转场介质。
- **允许保留的例外**：① 片头冷开场可用"黑屏→快速推近 / 震荡甩镜"建立威胁（属开场手法而非转场）；② 强节奏爆点的 0.5s 闪黑卡点可作为风格化 punctuation，但**不得作为常规场景过渡**。
- 自检：扫描全部 ⑫ 衔接 字段，凡出现"渐黑 / fade to black / 纯黑场过渡"且无上述承接手段的，判违规并改写。

### 8.3 分镜运镜层落实「镜头前置 + 动线参照」法则（反哺自镜头语言法则视频）
- **④ 运镜**字段须遵循"镜头前置"：先定光学风格（焦段/景别/景深）+ 摄影机路径 + 环境，再写主体**相对镜头**的运动；禁止把绝对方位（"向东走"）写进分镜，一律改"相对镜头方向/距离"（朝镜头走来 / 从画右出画 / 随镜头后退变大）。
- **切视角 = 切坐标系**：POV / 过肩(OTS) / 背后跟拍 / 侧跟 / 环绕，每换机位须以"新镜头"为参照重书动线。
- 运镜须有动机、一次 1-2 个核心运动、速度写明、光影置句尾；与模块②固定空间坐标、⑧ 人物站位朝向自洽，不漂移不反向。
- 情绪语法配对可入镜：缓推近+主体静止→压力/顿悟；后拉+主体逼近→威胁/体量；侧跟+行走→旅程/真实；锁定广角+极小动作→孤独/克制；手持跟拍+穿行→紧迫。

> **【Camera-First 正本锚点】** 本条是「镜头前置 / 以镜头为参照物写动线」的**唯一权威源（single source of truth）**。ai-manhua-onetake-prompt 的「镜头前置与动线参照法则」、deepwhite-shotlist-builder-zh-user 的分镜动线写法均**引用本条、不另写副本**，避免长期措辞漂移与互相打架。一镜到底专属细化（如运动×主体配对、图生视频变体）可在 onetake 内保留，但核心定义以本条为准。
