# Markdown 说明文档误生成分镜修复记录

## 问题

- 导入《猫大夫的快乐处方》这类 Markdown 方案/模板文档后，规划器把 `**类型：**`、`**风格：**` 等元数据当作动作节拍，生成数百段错误分镜。

## 修复

- 增加 Markdown 说明文档识别：检测多个加粗元数据字段且没有人物台词/旁白正文时，导入直接阻断并提示重新选择剧本。
- 解析器过滤分隔线、代码围栏和明确的说明标题，但保留 `# 第一场` 等真实场次标题。
- 规划器不再对普通 Markdown 剧本误判；说明文档识别作为导入入口门槛处理。

## 验证

- 新增说明文档识别回归测试。
- `npm test -- --run`：57 项通过。
- `npm run build`：前端与 Electron 构建通过。
- `npm run test:docs`：通过。
