# 剧本拆分工作台 9.30 升级方案（v1.0 → v1.1）

状态：升级方案定稿，尚未实施。范围：本地优先的自动拆分与一键生成能力升级，含多集结构、参考图本地识别与自动匹配、规则导演引擎、AI 可选增强层。

本方案记录 2026-09-30 需求裁定的最终结果，作为 v1.1 的需求与实施基线，不替代 v1.0 产品方案与技术方案，两者共同有效。

## 1. 升级动因

v1.0 已建立单集闭环：导入剧本、三模式拆段、14 条导演板、校验闸门、TXT/Word 导出。实际使用中暴露四个能力缺口：

1. **导入侧只能单张选图**，无法批量；且每段 6 张上限在导入时就禁用按钮，超限时静默丢弃改动。
2. **参考图归属靠人工勾选**，未利用图片命名、路径与画面信息。
3. **正文 14 条中 9 条没有任何生成路径**，只能逐字段手填，一键生成不存在。
4. **AI 接口配置入口被折叠并弱化**，未导入剧本时完全没有入口；且必须先配置接口才能使用。

同时明确两条新需求：输入通常是**整本剧本**（需自动分集），以及**本地优先、AI 可选**（不接 AI 也应跑通全链路）。

## 2. 设计原则

1. **本地优先**：核心能力零 API、零联网、本地计算；AI 为可选增强，默认关闭。
2. **骨架不动**：14 个正文条目的定义、顺序、标签一个不改，生成只填充内容，不新增、不删除、不调序。
3. **零篡改**：原稿节拍与原台词逐字保真，由机器校验兜底，AI 与规则均不得改动。
4. **机器可自检**：全部规则确定性、可重复、可单测，不接受"应该没问题"。
5. **单源真值**：方案、索引、归档与测试同步更新，不产生孤儿副本。

## 3. 总体架构

```text
导入（剧本 + 批量图片）
→ 分集识别与核对
→ 本地引擎 A：图像分析（图类 / 主体 / 光影色彩）
→ 本地引擎 B：规则导演（节拍分类 / 镜头模板 / 衔接生成）
→ 参考图自动匹配（三级置信度）
→ 一键生成（填充 10 条导演字段）
→ 校验闸门（不合格回退）
→ 分集导出
```

AI 增强层横挂在"本地引擎"与"一键生成"之间，**可开可关**；AI 输出未通过校验时自动回退本地结果，不阻断流程。

## 4. 数据模型升级（v1 → v2）

v1.0 产品方案已声明层级为"作品 → 集 → 场 → 15 秒段（P）→ 镜头（SC）"，但 v1.0 实现只落地了单集，且集号在 `planner.ts` 中硬编码为"第01集"。本次将"集"层正式落到数据结构。

```text
Project
├─ schemaVersion: 2
├─ title / contentType / defaultMode / platform
├─ episodes: Episode[]
├─ activeEpisodeId
└─ visual（作品级视觉文字设定）

Episode
├─ id / label（如"第01集"）/ index
├─ scenes / beats / segments / images
└─ confirmed（集级确认）
```

约束：

- 参考图片归属于**集**，不跨集复用；同一集内可跨段复用。
- 附加标记一律使用**可选字段**，保证旧快照可解析：`Shot.draftSource`（`local` / `ai` / `manual`）、`ReferenceImage.matchConfidence`（`high` / `medium` / `low`）、`ReferenceImage.matchSource`（`name` / `path` / `manual`）。
- 写迁移函数：v1 单集快照自动包装为仅含一集的 v2 结构，旧存档不失效。
- 工作台**只挂当前集**的段与镜，不一次渲染全本。

## 5. 分集识别

整本剧本导入后自动切集，规则与人工核对并重：

- **识别写法**：`第1集` / `第01集` / `第一集` / `第1话` / `EP01` / `Episode 01`，支持集号后接标题。
- **核对清单**：切分后先输出集清单（集号、标题、字数、场次数、切点行号），供人工核对。
- **可修正**：切点可人工调整，调整后重新生成集清单。
- **兜底**：完全识别不到集标时，按场次或字数均分，并显式告警（`EPISODE_SPLIT_UNVERIFIED`），不静默硬切。

## 6. 本地引擎 A · 图像分析

新增本地分析模块，零 API、零联网，输出供匹配与字段填充使用：

| 输出 | 判据 |
|---|---|
| 图类（人物 / 场景 / 道具） | 路径关键词 > 文件名关键词 > 画幅比例；浏览器原生人脸检测可用时仅作加分项，不作主路径 |
| 主体 | 文件名主干去噪（如"林夏_正面_01"→"林夏"）后与剧本说话人名册、场景名册比对 |
| 主色与影调 | 缩略图主色调（k-means 取 3 色）、平均亮度、饱和度、色温倾向 |
| 空间与光源方向 | 画面上下/左右亮度分区，判断光源方位、室内外与昼夜 |

主色与影调结果可直接作为⑦光源、⑧氛围的生成依据。

**硬缺口**：本地无法产出"外观描述"（发型、服装、材质等）。缺图或未确认时，① ② 走 v1.0 已有的人工文字设定回退，并按 v1.0 约定标注"文字设定"来源。

## 7. 本地引擎 B · 规则导演

替代 v1.0 的机械切分（按字数凑断、镜头数 = max(3, 节拍数)），引入剧情感知规则：

1. **节拍分类**：动作 / 对话 / 情绪 / 场景建立。依据动作词表、标点密度（感叹、疑问、省略）、句长节奏综合判定。
2. **镜头模板**：按节拍类别套用预设镜头语言——动作→中近景·35mm·跟拍；对话→过肩·50mm·静止；情绪→特写·85mm；场景建立→大全景·24mm。
3. **连续性继承**：相邻镜的⑨人物站位、⑦光源自动承接，避免无过程跳变。
4. **⑭衔接生成**：从合规衔接手段池取用——动作接动作、视线引导、遮挡转场、匹配剪辑、J-Cut、L-Cut、声音先入或延后、空镜缓冲、同向运动顺接、光影变化接、焦点转移接。**禁止**闪黑、闪白、黑场、白场、叠化、交叉溶解、淡入淡出、单纯推、单纯拉等低级转场，由本地禁词表拦截。

规则引擎为确定性实现，全部可单测。执行完成后 10 条导演字段均有初始内容，不依赖 AI。

## 8. 参考图自动匹配

匹配结果分三级置信度，**不做全静默自动绑定**：

| 置信度 | 条件 | 处理 |
|---|---|---|
| 高 | 精确命中唯一场景或唯一角色 | 自动绑定，立即可用 |
| 中 | 命中多个候选（角色跨多场等） | 绑定全部出场段，界面标黄等待人工复核 |
| 低 | 主体为空或无法命中 | 进入"未分配区"，不猜测、不丢弃 |

约束：

- 每段最多绑定 **6 张不同参考图**（沿用 v1.0 契约）。超出时按置信度取前 6，**溢出的图片保留在图片库并标记"已入库未绑定"**，修正 v1.0 静默丢弃的问题。
- 同一张图可绑定多个段落。
- 低置信度与未分配项必须显式可见，不得隐藏。

## 9. 一键生成

交互为单一动作：

```text
上传剧本 + 批量图片 → 自动分集 → 选中一集 → 按"一键生成"
→ 图像识别 → 自动匹配 → 填充 10 条导演字段 → 过校验 → 出结果
```

生成范围与约束：

- **只填充 10 条**：③景别、⑤焦距、⑥运镜、⑦光源、⑧氛围、⑨人物站位 + 朝向、⑩肢体动作、⑪微表情、⑬音效、⑭衔接。
- **禁改 3 条**：①人物参考图的描述、②场景参考图的描述、⑫台词 / 内心OS。④构图由一键生成根据节拍与镜头模板自动生成；①②来自参考图与文字设定，⑫来自原稿，均由既有链路或规则注入。
- **幂等**：只补空白条目，已有人工内容不覆盖；需覆盖时由人工显式勾选。
- **队列**：串行执行，提供进度、可中断、失败隔离；单张识图或单段生成失败不阻断整体。
- **确认链**：生成改动过的段落 `confirmed = false`，同时标记该段「导演决策已生成」（`Segment.directorGenerated`），界面上本地与 AI 生成条目可区分来源。人工确认属**建议复核项**，不再单独阻断导出（2026-09-30 二次裁定，见第 18 节）。

## 10. AI 可选增强层

- **总开关，默认关闭**。不接 AI 时全链路可用。
- 开启后获得三项增强：图片外观描述、剧情语义分镜、字段内容起草。
- **接口配置入口**上移至顶栏，任何时候可打开，未导入剧本时同样可见，不再折叠弱化。
- 配置项：接口地址、模型、密钥，附**「测试连接」**按钮，填完即可验证连通，不必等到生成时才发现错误。
- **降级规则**：AI 生成的 10 条字段与分镜切分必须通过本地校验；未通过则自动回退本地规则结果并提示，不阻断交付。
- 密钥不写入项目快照。

## 11. 校验闸门增补

沿用 v1.0 全部闸门（含台词保护、节拍覆盖、15 秒时长、字段完整、图号占位拦截、参考图上限、人物锚点漂移、连续性告警等）。本次新增：

| 编号 | 级别 | 含义 |
|---|---|---|
| `SHOT_DURATION_MAX` | 阻断 | 单镜时长超过 12 秒（v1.0 未设上限，本次补齐） |
| `TRANSITION_FORBIDDEN` | 阻断 | ⑭衔接命中转场禁词表 |
| `AUTO_MATCH_LOW_CONFIDENCE` | 建议复核 | 存在低置信度匹配或未分配图片 |
| `EPISODE_SPLIT_UNVERIFIED` | 建议复核 | 分集结果未经人工核对 |

硬性不变量（任何生成方式都不得破坏）：节拍完整覆盖、不重不漏不乱序；原台词、说话人与顺序逐字不变；每段镜头时长之和等于 15 秒；14 条不缺项、不合并、不乱序。

**分级口径（2026-09-30 二次裁定）**：上表「阻断」只保留事实类（输入不完整、原图描述未确认、剧本结构/台词不一致）与内容安全项；`DIRECTOR_UNCONFIRMED` 等人工确认类降为**建议复核**，导出按钮不因任一条问题永久失效。分级由单源闸门表 `issuePolicy` 唯一决定，详见第 18 节与产品方案 v1.1 第 8、12 节。

## 12. 界面结构

- **顶栏**：导入 / **一键生成（主操作）** / 接口设置 / 保存项目 / 导出 TXT / 导出 Word。
- **集列表**：全本集号一览，选中哪集编辑哪集。
- **三栏**：原剧本 / 导演板 / H3 成品与质检（沿用 v1.0）。
- **新增区域**：未分配图片区、生成进度面板、置信度标黄提示、条目来源标记。

## 13. 存储方案

整本改造后容量远超浏览器本地存储上限，必须同步升级存储：

- 持久化由 `localStorage` 迁移至 **IndexedDB**（容量足够承载整本项目）。
- 参考图以 **Blob** 存放于 IndexedDB，项目数据只保存哈希与摘要，不内嵌 base64 预览。
- 工作台只加载当前集，控制内存与渲染压力。
- Electron 项目快照仍支持另存 JSON，供归档与迁移；原图不入快照，需另行留存。

## 15. 实施阶段与验收

按阶段推进，每阶段测试全绿后单独提交：

1. **A**：数据模型 v2、IndexedDB 存储、分集识别与集切换。
2. **B**：接口配置面板上移、测试连接、AI 可选开关。
3. **C**：批量图片导入、本地图像分析、三级置信度匹配。
4. **D**：规则导演引擎、一键生成、新增闸门。
5. **E**：AI 增强通道与回退策略。
6. **F**：方案文档、索引与过程归档同步。

验收基准：

- 不配置任何接口，导入整本剧本与批量图片后，一键生成可产出通过全部闸门的 14 条分镜。
- 开启 AI 后，输出发生变化但校验结果仍全绿；人为制造不合格 AI 输出时，系统回退本地结果并提示。
- 同一输入重复执行一键生成，结果一致（幂等）；已有人工内容不被覆盖。
- 超额图片不丢失，超限、低置信度、未分配均有显式提示。

## 16. 风险与边界

1. **本地图像外观描述不可得**：本地只能给出图类、主体与光影色彩。人物与场景的具象外观依赖人工文字设定或 AI 增强，这是本方案的唯一硬缺口。
2. **自动匹配不保证全对**：同一角色跨多场、相似场景易混。因此保留"中置信度标黄复核"层，不做全静默绑定。
3. **整本规模压力**：不迁移至 IndexedDB 必然超出容量上限，存储升级是阶段 A 的前置条件，不可跳过。
4. **分集格式不确定**：采用"识别 + 人工可核对可调整"策略，不硬猜、不静默切分。
5. **规则分镜的审美上限**：规则引擎保证合规与一致性，不保证导演级创造力；追求更高表达时需启用 AI 增强或人工介入。

## 17. 裁定记录（2026-09-30）

本次升级范围由以下裁定收敛，按时间顺序记录：

1. 批量导入不设数量限制；每段 6 张为**绑定**上限，非导入上限。
2. 由系统**自动识别**参考图并匹配段落，不依赖用户命名规范。
3. 交互为"上传剧本与图片后按一个按钮生成"；**正文骨架保持既定 14 条不变**。
4. 增加**测试连接**按钮，并解决接口配置入口不可见问题。
5. 输入为**整本剧本**，工具需自动按剧情拆分镜并生成。
6. 集与集的组织方式采用**一本一个项目、内含多集**。
7. 分镜严格守 **15 秒一段**规格，不放宽。
8. **本地优先、AI 可选**：不接 AI 也应完成本地识别、拆分与生成。

## 18. 二次修订 · 闸门分级与生成范围（2026-09-30 晚间裁定）

第 1–17 节为 v1.1 原始基线，已按阶段 A–F 实施完毕；本节登记第二轮裁定，与前文冲突处以本节为准。

**范围**：不放松真正的内容安全与台词完整性阻断，也不让导出按钮因某一条问题永久灰掉。

1. **闸门分级收敛**：新增单源闸门表 `src/platforms/minimax-h3/validator.ts` 的 `issuePolicy`，`add()` 不再由调用点指定级别。阻断（error）只保留事实类（输入不完整 / 原图描述未确认 / 剧本结构、台词不一致）与内容安全（转场禁词、图号占位）；人工确认类降为建议复核。
2. **导出交互**：导出按钮仅在未载入项目或生成进行中禁用。本集无阻断即导出本集；本集有阻断则给出「全书阻断清单」——按集分组、标注分类与段镜位置、逐条跳转，并单列可导出集支持按集导出。
3. **生成范围**：新增「全部分集生成」，逐集分析、匹配与回填，单集失败隔离，整本一次写入。
4. **标记**：`Segment.directorGenerated` 记录导演决策是否已生成，段与导演板显示「已生成」/`已生成 X/Y 段`；人工 `confirmed` 仅作复核标记。
5. **改动清单**：新增 `src/platforms/minimax-h3/gate.ts`（按集审计）；改造 `validator.ts`、`store.ts`（`applyGenerationBatch` / `focusTarget`）、`App.tsx`、`styles.css`、`core/model.ts`（`directorGenerated`、`Issue.category`）、`core/planner.ts`；同步单测、e2e 与文档契约。
