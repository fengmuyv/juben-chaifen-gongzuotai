## 根因（三类，均为「正文 × 剧本」错位）

1. **叙述行误判为台词（P0-1）**。解析器把「冒号前 ≤20 字」当作说话人，于是 `余额：2,430。` /
   `门上贴着三个字：严禁入内。` / `画面猛地拉开：…` / `发送时间：十一点五十二分。` /
   `下面有人喊："解完这根就下来！"` 全部被当成 ⑫ 台词 —— 既污染台词，也让「确凿台词行」误判成立。
2. **非正文块提前解屏（P0-2）**。真实定稿稿在正文前有**前言统计表**、正文后有**附录「补写说明」**
   （`三、路 A 补写说明（画面密度）` / `动因：…` / `做法：…` / `六道护栏（全部通过）：…`）。
   这些「标签：值」行一旦被判成台词，就直接把非正文块解屏，文档层账目灌进分镜。
3. **名册污染（P0-3）**。名册判据只有「像不像人名」的粗筛，方位短语、字段名词尾、泛指主体词
   （`窗口后` / `电话那头` / `发送时间` / `下面有人喊` / `一步一步`）都能登记进名册，
   而 ⑨站位 / ④构图只写名册里的人 —— 于是站位写出「左侧窗口后与右侧电话那头」这类代称。

生成本文侧（P1）：⑦光源、⑧氛围在无参考图时**回退为一条常量**，全片同一句，与场次昼夜无关。

## 实施

### 正文识别层（`src/core/parser.ts`，判据单一来源）

- `briefHeadings` 扩容：补入真实定稿稿的前言统计表与附录标签
  （`全剧实测` / `源脚本系列` / `定稿状态` / `残余` / `附录` / `后记` / `总账` / `动因` / `做法` /
  `六道护栏` / `三条验收断言` / `画面密度` / `叙述` / `路A补写说明`）。
- `headingPartsOf` 增加 `raw`，新增 `isBriefLabel(label, raw)`：使**括注标题**
  （`三、路 A 补写说明（画面密度）`）也能按词干命中；`headingKindOf` 改用之。
- **人物判据单源化**：`subjectStopwords` / `partWords` / `environmentOnly` / `isCastName` 从
  `director.ts` **迁入并 export**（生成层改为 import，不再各写一套词表）。
- 新增判据：`locativeTail`（方位尾）、`quoteNoise`、`quantifierPhrase`（数词＋量词，**含「步」**）、
  `fieldLabelTail`（字段名词尾：时间/日期/时长/号码/账号/余额/金额/数量…）、
  `vaguePerson`（含 `有人` / `某人` / `那人` / `这人` 的舞台指示）。
- 新增 `speakerTrusted(label, cast)`：说话人是否可信 —— cast 命中 → 真；方位尾 → **假**；
  编号角色（`黑衣人甲`）→ 真；角色称谓且 ≤6 字 → 真。`isDialogueLine` 升级为
  `isTrustedDialogueLine(line, cast)`。
- **skip 块退出收紧**：非正文块内遇 `headingKindOf !== 'none'` 只切换 skip 类型；人物设定块内
  `姓名：描述` 条目**只登记姓名、不解屏**；只有场次标题或**确凿台词行**才退出 skip。
- 主循环：`kind === 'dialogue' && !speakerTrusted(label, cast)` → 按 **action** 处理（原文零篡改保留），
  且不登记名册。

### 生成本文层（`src/platforms/minimax-h3/director.ts`）

- 删除本文件内 `partWords` / `environmentOnly` / `subjectStopwords` / `isCastName` 等重复定义，改从
  `parser` 单一来源引入。
- 新增场次标记单一来源 `SceneMarker` + `sceneMarkerOf(title)`（内 / 外 ＋ day / dusk / night）。
- `lightFor(analysis, sceneTitle = '')` / `atmosphereFor(analysis, sceneTitle = '')`：无参考图时**按场次标记
  派生**（夜间室内 / 夜间外景 / 黄昏 / 日间室内 / 日间外景…），替换原文常量
  `'自然散射光，中性色温，中等照度'` / `'环境光均匀，情绪平稳'`；`genericAmbience` 复用同一标记。
- `generateEpisodeDrafts` 取本镜所属场景标题并传入 ⑦⑧。

## 口径（本轮新增 · 改代码前必看）

- **叙述行降级规则**：`标签：值` 行当且仅当 `speakerTrusted(label, cast)` 为真才算台词。真台词 =
  `beat.kind === 'dialogue'` **且** `beat.dialogue.kind === 'dialogue'`；`内心OS` / `旁白` 由专门分支
  产出（`kind: 'inner' / 'narration'`），**不计入说话人判据**。
- **名册判据（`isCastName`，单一来源）**：长度 ≤5、无标点 / 无引号 / 无字母数字，且不命中
  占位名 / 功能词 / 序数短语 / 数量短语（含「步」）/ 副词起首 / 代词起首 / 非人片段 / **字段名词尾** /
  **泛指主体词** / 方位尾 / 非正文块标题 / 停用词 / 环境词 / 部位词。
- **泛称说话人保留**：`庄稼汉子` / `汉子` / `妇女` / `大爷` / `记者甲` 是剧本里真实存在的**发言主体**
  （原文即 `庄稼汉子：住手！…`），保留在名册，⑨站位仍写得出主体 —— 不得当作污染清除。
- ⑦光源 / ⑧氛围 / ⑬底噪**共用** `sceneMarkerOf` 一套场次标记，禁止各自回退为常量或另写第二套表。
