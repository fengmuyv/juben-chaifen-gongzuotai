# 输入图片与分镜正文分区实施记录

## 1. 需求

用户要求将输入图片输入框与分镜正文输入框分开，避免参考资产编辑和分镜正文编辑混在同一操作区。

## 2. 实施

- `src/App.tsx` 将参考图片导入、绑定、描述确认和 AI 描述移动到独立的“输入图片”面板。
- “导演板”仅保留视觉文字设定、段落选择、镜头正文和确认操作。
- `src/styles.css` 将工作区从三栏调整为四栏，并为窄屏保留纵向堆叠规则。
- E2E 增加面板存在性与隔离断言，确认导演板不再包含图片设置区。

## 3. 验证

- `npm run build` 通过：TypeScript、Vite、Electron 构建均通过。
- `npm run test:e2e -- --grep "sample flows|mobile layout"` 通过：2/2。
- 既有图片导入、描述确认、分镜预览数据流未改动。

## 4. 影响与回滚

本轮只调整界面分区和响应式布局，不改变项目数据模型、导出格式或图片绑定规则。回滚依据为本次 Git 提交；索引已同步更新。
