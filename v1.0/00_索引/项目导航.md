## 实施资产

- `src/core/`：原稿结构、节拍、15 秒草稿规划和版本化数据模型。
- `src/platforms/minimax-h3/`：H3 专属 14 字段骨架、阻断校验和 Markdown 编译。
- `src/App.tsx`、`src/store.ts`：三栏导演工作台、浏览器草稿恢复和人工确认。
- `electron/`：受隔离的桌面窗口、类型化文件对话框和原子写入。
- `tests/unit/`、`tests/e2e/`：引擎与界面流程验证。
- `99_过程归档/2026-09-28_阶段一闭环实施记录.md`：本次来源、实施范围、验证及剩余边界。

运行：`npm install` 后 `npm run dev:desktop`；浏览器预览可运行 `npm run dev`。`npm run verify` 执行文档、单元、构建和界面测试。浏览器草稿存于当前浏览器本地存储，正式留存请使用“保存项目”导出 JSON 快照。
