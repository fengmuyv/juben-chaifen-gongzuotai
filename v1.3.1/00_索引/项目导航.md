## 实施资产

- `src/core/`：原稿结构、节拍、15 秒草稿规划、v2 版本化数据模型与 v1→v2 迁移。
- `src/core/episodes.ts`、`src/core/parser.ts`：整本分集识别、集清单与切点行号；分集切点单一来源 = `parser.episodeHeadingOf`（三态：真集标 / 集头导语），`episodes.ts` 不另写正则，真集标优先、同集号取最后切点。解析器含非正文块识别（`briefHeadings` 单一来源：来源 / 类型 / 人物设定 / 故事梗概 / 大纲 / 世界观等标题连同下属内容整体剔除）、`isMetadataLine` 元数据行过滤与人物名册提取（`speakerNameOf` + `isCastName` + 说话人可信度 `speakerTrusted` + 角色称谓表 `roleSpeaker`）。
- `src/core/storage.ts`：IndexedDB 持久化与 v1.0 浏览器草稿迁移。
- `src/core/analyze.ts`、`src/core/match.ts`、`src/core/pixels.ts`：本地图像分析（图类 / 主体 / 光影色彩）与三级置信度匹配。
- `src/platforms/minimax-h3/director.ts`：规则导演引擎。生成单一来源 —— 身体动作 / 面部动作 / 声音声源三张证据表驱动 ⑧ ⑨ ⑬，④ 构图与 ⑦ 站位由同一 `Staging` 派生；人物识别取真实姓名（8 条判据剔除部位词 / 数量副词 / 元数据词，双人分列左右三分之一）。⑧ ⑨ 原稿有证据优先取证，无证据时按「情绪档 `emotionDesigns` + 跨集人物弧光 `arcStages`」设计，仅空镜填「无」。⑬ 音效 = 原稿声源证据 ＋ 场景空间底噪（`ambienceCues` 具体地点 + `genericAmbience` 内外 / 昼夜兜底），按环境主题去重；场景无环境线索时仍填「无」。⑭ 衔接按**镜头证据选型**（`transitionRules` 带前提 + `pickTransition`），段末分「本集收束 / 换场次重设轴线 / 同场次延续」三种口径。
- 名册与「⑨ 站位」（**产品方案正本编号**）：名册**唯一发现通道** = 人物设定块 ＋ 可信说话人（`parseScript().cast`）；叙述句主语 `narrationSubjects` 降级为**佐证通道**，只在「已确证姓名」或命中 `roleSpeaker` 角色称谓表（`小女孩` / `老人` / `鬼子兵`）时补登记。`sceneAnchorOf` 产出**场次轴线锚**（本场人物按原稿出场次序，整场锁死），`stagingFor` 的 `sideOf` 是「（锚 + 人名）→ 左/右」的**纯函数**，与他是否同框无关；`shotSpeakers` 让可信说话人一律进主体（`评委A` / `投资方代表甲` 不受名册判据限制），⑫ 台词仍保留原稿原文。
- **字段编号口径（2026-10-01 扫尾完成）**：正本 = `⑦光源 ⑧氛围 ⑨站位 ⑩肢体动作 ⑪微表情`。`src/` 与 `electron/` 下的旧写法（`⑦站位` / `⑧肢体动作` / `⑨微表情`）**已全部清零**；`99_过程归档/` 与 `01_产品方案/`、`02_技术方案/` 的历史文本保留当时写法，**不追改**（历史记录不得篡改）。
- `src/platforms/minimax-h3/rules.ts`：闸门规则正本（**叶子模块**，不依赖任何业务模块）。转场禁词、单镜时长、闸门分级表 `issuePolicy` 都在这里，供生成层 `director`、校验层 `validator`、审计层 `audit` 共用 —— 规则必须比三者更低一层，否则会成环。
- `src/platforms/minimax-h3/audit.ts`：**通用一致性审计**（`auditEpisodeContent`）。判据全部来自原稿本身与生成端同源函数，**与具体剧本无关**，换任何原稿都自动执行，不需要为每个项目单独升级。覆盖：越轴（`AXIS_JUMP`）、⑭ 前提不成立（`TRANSITION_PREMISE`）、⑫ 说话人不可信（`SPEAKER_UNTRUSTED`）、⑨ 写出名册外主体（`BLOCKING_UNKNOWN_SUBJECT`）、③ 景别与入画人数**两个方向**的冲突（`SCALE_SUBJECT_CONFLICT`，判据 = `director.scaleSubjectConflict`：人脸特写收不下 ≥2 人、人物档景别套不住空镜）、④⑨ 主体位置相反（`STAGING_COMPOSITION_CONFLICT`）。位置解析 = `director.sidesIn`（与 `stagingFor` 互为逆函数的单一来源）。由 `validate()` 自动调用，质检面板与导出闸门随之生效。
- **③ 景别档位唯一来源 = `director.gradeForShot(category, subjectCount)`**（③⑤⑥ 绑成一个升降一体的档位单元，与 ④ 构图的景深取同一个 grade）：≥2 主体 → `双人中近景`；0 主体（空镜 / 内心OS 覆盖镜 / 纯环境镜）→ 空间档 `大全景` / `全景`；其余保持基准档。**不得**再直接读 `shotTemplates[category].scale` 写镜头。
- `vitest.audit.config.ts`、`tests/audit/`、`scripts/audit-script.mjs`：任意剧本一键体检（`npm run audit:script -- "<剧本路径>"`）。与 `npm test`（`tests/unit/**`）配置隔离，日常单测不受真稿规模影响；换剧本只换路径、不改代码。
- `src/platforms/minimax-h3/validator.ts`：单源闸门表 `issuePolicy`（事实类与内容安全阻断、人工确认转复核）与全部校验闸门；闸门规则已下沉 `rules.ts` 并在此原样再导出。`validate()` 会自动执行通用一致性审计。
- `src/platforms/minimax-h3/gate.ts`：按集导出审计（阻断项 / 复核项 / 可导出集），支撑全书阻断清单与按集导出。
