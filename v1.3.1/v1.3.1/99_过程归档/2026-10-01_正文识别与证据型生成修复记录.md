# 正文识别与证据型生成修复记录

## 老大反馈（2026-10-01）

1. 音效、构图、肢体动作都不对。
2. 要识别不同人物。
3. 对正文的识别有误，经常把故事梗概、来源和人物设定也加入分镜。

裁定口径：选项 A —— 证据优先 + 一致性硬约束。

## 实测取证（修复前）

用 9 句最小样例跑本地规则导演，实际产出：

| 原稿 | 修复前产出 |
|---|---|
| 窗外雷声滚过，雨点砸在玻璃上 | 音效：脚步急停的摩擦声与呼吸加重 |
| 陆时渊站起身，一步一步走到她面前 | 音效：拳脚击中躯干的闷响与衣物摩擦声 |
| 她把手里的伞甩在地上，水渍溅开 | 音效：开阔环境声场，远处车流与鸟鸣 |
| 苏清苒推门而入，脚步在门口停住 | 肢体动作：无（真动作漏证） |
| 陆时渊坐在沙发上，指尖敲了敲桌面 | 肢体动作：整句照抄 |
| 窗外雷声滚过，雨点砸在玻璃上 | 肢体动作：整句照抄（环境描写被当动作） |
| 苏清苒猛地转身，眼泪落下来 | 同一句同时进 ⑧ 肢体动作与 ⑨ 微表情 |

混合文档实测：`**人物设定：**`、`**故事梗概：**` 标题行虽被过滤，但**标题下的正文行全部成为节拍**，
挤占镜号（真实剧本的推门镜头被推到 SC05）；纯文本 `故事梗概：` / `人物设定：` 两行本身也成了节拍。

## 根因

1. **⑬ 音效**：`director.ts` 的 `soundTemplates` 每类仅 2 条，按 `(段序+镜序) % 2` 机械轮转，与原稿零关联。
2. **④ 构图**：`compositionTemplates` 同为 2 条轮转，且与本镜已定事实互相矛盾 ——
   景别算作大全景却写「近景前景」；站位在右三分之一却写「主体位于中央偏左」；纯雷雨空镜写「交锋双方分列左右两侧」。
3. **⑧ 肢体动作**：只认「镜头第一条节拍且 kind=action」+ 一张漏词严重的动词表，命中即整句照抄；
   `推门 / 停住 / 甩 / 溅` 均不在表内，而环境声描写反而整句写入。`store.ts` 与 `director.ts` 取证口径还不一致。
4. **正文识别**：说明文档识别只拦「≥3 行加粗元数据且无台词」的纯说明文档；混合文档（人物设定 + 故事梗概 + 真剧本）
   直接放行，块内正文逐行成为节拍。
5. **人物识别**：全项目只在一处用了说话人（整集一句站位），字段大量使用「人物」泛指。

## 实施

- `src/core/parser.ts`：新增非正文块识别（`briefHeadings` 单一来源 + `headingKindOf` 三态判定
  `block / field / none`）。`block` = 块标题连同下属内容整体丢弃；`field` = 只丢本行。
  块内遇分集标记、场次标题或确凿台词行即退出，不吞正文。人物名册 `cast` 从人物设定块条目提取。
- `src/platforms/minimax-h3/director.ts`：
  - 删除 `soundTemplates` / `compositionTemplates` / `performanceTemplates` 三张编造句表与 `actionWords`。
  - 新增证据表：身体动作（命中即给出方位/动线）、面部动作、环境排除、声音声源、景别景深档位。
  - ⑧ ⑨ ⑬ 一律子句级取证 + 人物归属；无证据填「无」；面部子句不再重复进 ⑧（去掉串味）。
  - ④ 构图与 ⑦ 站位由同一 `Staging` 派生：主体位置同源，结构上不可能矛盾；
    空镜不再写「交锋」，景深不写「主体」。
  - ⑦ 站位逐镜推进并按真实人物分列，双人写明左右三分之一与轴线。
  - 人物识别：姓名取自人物设定块 + 台词说话人 + 叙述句主语；部位词（指尖 / 眼 / 脚步）与
    数量副词（一步一步）不误判为人物。纯环境镜不继承上镜双人站位。
  - 衔接池去掉硬编码剧情内容物（信封 / 钟表 / 窗棂 / 门把手），改为机制描述。
  - 镜头意图截取首个子句并限长，标题行不再塞入整句原文。
- `src/store.ts`：写入边界证据字段校正范围由 `action / performance` 扩到 `+ sound`；
  ④ 构图保留人工与 AI 写法，仅在主体位置与 ⑦ 站位矛盾时收敛（`compositionContradictsStaging`）。
- `electron/script.ts`：AI 提示词补构图一致性、音效取证、人物指名三条硬约束。

## 需要老大确认的口径

- **空镜**（原稿只有环境或声音描写）现在写「本镜无人物入画」，不再继承上镜主体。
- **回合并镜**（15 秒 / 镜）出现空镜时不再自动保留人物站位。
- **⑬ 音效严格取证**：台词镜与无声音证据的镜头填「无」。如希望台词镜带空间底噪，
  需另行裁定（当前按「无依据即无」执行）。
