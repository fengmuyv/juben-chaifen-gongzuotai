# 阻断清单自动修复实施记录

## 目标

针对“场次或节拍与原稿不一致”“原台词、说话人、顺序或原文位置被修改或遗漏”两类事实阻断，增加无需逐条手动修复的自动修复入口。

## 实施

- 新增 `src/platforms/minimax-h3/repair.ts`，以当前原稿为正本重新规划集内场次、节拍、段落和台词。
- 旧导演字段、锁定状态和参考图按节拍 ID 稳定迁移；无法定位原稿范围或未解析出节拍时返回未解决项，不强行覆盖。
- 阻断清单增加“自动修复全部阻断”和“修复本集”，修复后自动重新校验；自动重建结果保持待人工确认状态。
- 新增自动修复单测，覆盖原台词恢复、导演意图保留和重复修复稳定性。

## 验证

- `npm test`：4 个测试文件、118 项通过。
- `npm run build`：TypeScript、Vite 和 Electron 构建通过。
