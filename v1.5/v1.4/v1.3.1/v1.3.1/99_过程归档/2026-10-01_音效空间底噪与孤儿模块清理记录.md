# 音效空间底噪与孤儿模块清理记录

## 老大反馈（2026-10-01 · 三次）

1. **⑬ 空间底噪要根据剧情所处的环境加**（承接上轮「⑬ 音效严格取证、台词镜填『无』」的待裁定项）。
2. **清理**孤儿文件（上轮登记的 `src/core/text.js`、`shared/text.js`，属单源违规残留）。
3. 清理完**上传一份最新版本**。

## 实测取证（修复前）

- ⑬ 音效口径为「只从原稿可观察声源取证，无证据填『无』」：真实剧稿里**台词镜与纯叙述镜全部填「无」**，与老大的期望相反。
- 真实剧稿（伪装成 `.txt` 的 docx，正文 113,497 字）实测：60 集 / 212 个场景 / 4565 镜。

## 根因

1. ⑬ 与 ⑧⑨ 同源问题：把「原稿没有声音证据」等同于「本镜没有声音」，而每场戏都处在某个**有环境的空间**里，底噪本应常驻。
2. 环境信息其实**已经在剧本里**：场次标题写明地点与昼夜（本次真实剧稿用标准场次头 `场景 3　日.内　办公室`），上一轮只是没取用。
3. 孤儿模块属于历史单源违规：`src/core/text.js`、`shared/text.js` 是 `electron/text.ts` 的失效编译副本，全仓零引用（`git ls-files` 只跟踪 `electron/text.ts`）。

## 实施

### ⑬ 空间底噪（`src/platforms/minimax-h3/director.ts`）
- 新增单一来源表 `ambienceCues`：`[场景匹配, 主题, 底噪描述]`，覆盖医院 / 办公室 / 资料室 / 客厅 / 餐厅 / **片场** / 法庭 / 教室 / **晒谷场·祠堂·村口** / 楼道 / 街 / 车内 / 工地 / 天台 / 山野等常见场景。
- 新增 `genericAmbience`：具体地点未命中时，由剧本自带「内 / 外」+ 昼夜标记派生通用底噪（室内日/夜、室外日/夜、仅昼夜）。**这是剧本自身信息，不是臆测。**
- `soundFor(texts, sceneTitle = '')`：**原稿声源证据优先 → 再按场景环境补一层空间底噪**；证据与底噪都没有时填「无」。
- `ambienceTopicOfSound`：把声源证据映射到环境主题（雨 / 风 / 雷），**原稿已写雨声就不再补雨声底噪**，避免重复。
- `sourceFieldsForShot` 传入本镜所属场景标题（节拍缺场次时退回所在段）。
- 顺手补一处真实召回缺口：风声证据正则由 `风(?:声|吹|过|起|刮|雨|夜)` 扩为含 `穿`（`风穿过栏杆` 原先漏证）。

### 孤儿模块清理
- 备份 → 校验 → 删除：`src/core/text.js`、`shared/text.js`（各 824 字节，备份留档 `.workbuddy/temp/orphan-text-backup-20261001/`），并移除空目录 `shared/`。
- 核验：全仓零引用；`tsconfig*.json` / `vite.config.ts` / `vitest.config.ts` 均未引用 `shared/`。**导入正本唯一 = `electron/text.ts`。**

## 口径（本轮新增，改代码前必看）

- ⑬ 音效 = **原稿声源证据（优先）＋ 场景空间底噪**；去重按环境主题（雨 / 风 / 雷）。
- 底噪只描述环境声层，**不得编造对白、配乐或具体剧情音效**；场景无任何环境线索（如「未标注场次」）时仍填「无」。
- 底噪来源**单一** = `ambienceCues` + `genericAmbience`；不得另写第二张环境词表。
