# 剧本拆分工作台

AI 漫剧的剧本拆分与分镜编译器。把整本剧本导入，自动分集拆场，按 14 项固定字段生成分镜表，校验后一键导出 Word / TXT。
桌面端为 Electron，**本地优先、离线可用**；AI 增强是可选路径，不配置接口也能完整出稿。

---

## 一、这个仓库是什么

**版本归档库，不是常规代码仓库。**
每一版一个顶层文件夹，版本号越大越新。

- **最新版 = 顶层版本号最大的那个目录**（当前为 `v1.8/`）
- 早期版本按归档规则整体嵌套进上一版目录（`v1.7/v1.6/v1.5/…`）
  这是归档策略的结果，**不是目录损坏**，也不需要全部下载。

## 二、如何下载

**只要最新版（推荐）**

1. 进入 `v1.8/` 目录
2. 点右上角 `Code → Download ZIP`

**要完整历史**

```
git clone https://github.com/fengmuyv/juben-chaifen-gongzuotai.git
```

整包约 2–3 MB。

## 五、本地运行

要求：Node.js 20 以上（实测 22 可用）、npm。

```
npm install
npm run dev          # 浏览器开发模式，127.0.0.1:5173
npm run dev:desktop  # Electron 开发模式
npm run build        # 类型检查 + 打包
npm start            # 启动已构建的桌面端
```

自检（作者侧完整验证链）：

```
npm run verify       # 文档契约 + 单元测试 + 构建 + e2e
```

技术栈：Electron · React 19 · TypeScript · Mantine · Zustand · zod · Vite。

## 七、数据与隐私

- 项目数据全部保存在本机 IndexedDB，不上传任何服务器。
- AI 增强可选：不填接口地址与密钥时，全程走本地规则出稿。
- 仓库内不含真实密钥或私有服务地址。

## 八、核心约束（产品不是通用生成器）

- 段 = 15 秒，段内各镜时长之和恒等于 15 秒，单镜锁在 1–12 秒。
- 14 项分镜字段固定顺序，不增不减。
- 台词按原稿逐字保留，不做改写。
- 资产只分「人物 / 场景」两类，按导入时选择的分类参与匹配。
