## 实施资产

- `src/core/`：原稿结构、节拍、15 秒草稿规划、v2 版本化数据模型与 v1→v2 迁移。
- `src/core/episodes.ts`、`src/core/parser.ts`：整本分集识别、集清单与切点行号。
- `src/core/storage.ts`：IndexedDB 持久化与 v1.0 浏览器草稿迁移。
- `src/core/analyze.ts`、`src/core/match.ts`、`src/core/pixels.ts`：本地图像分析（图类 / 主体 / 光影色彩）与三级置信度匹配。
- `src/platforms/minimax-h3/director.ts`：规则导演引擎（节拍分类 / 镜头模板 / 连续性继承 / 合规衔接生成）。
- `src/core/migrate.ts`：v1.0 单集快照 → v1.1 多集结构迁移。
- `electron/script.ts`：可选 AI 文本增强通道与「测试连接」。
- `src/platforms/minimax-h3/`：H3 专属 14 字段骨架、阻断校验和 TXT 正文编译。
- `src/App.tsx`、`src/store.ts`：三栏导演工作台、浏览器草稿恢复和人工确认。
- `electron/`：受隔离的桌面窗口、类型化文件对话框和原子写入。
- `tests/unit/`、`tests/e2e/`：引擎与界面流程验证。
- `99_过程归档/2026-09-28_阶段一闭环实施记录.md`：本次来源、实施范围、验证及剩余边界。
- `src/core/word.ts`：Word 剧本正文读取与通过质检后的 14 字段分镜导出。
- `src/core/images.ts`、`src/core/vision.ts`、`electron/vision.ts`：参考图片压缩预览、SHA-256 和可配置视觉模型描述。
- `99_过程归档/2026-09-28_Word与参考图描述实施记录.md`：本轮变更、验证和存储边界。
- `99_过程归档/2026-09-30_9.30升级实施记录.md`：v1.1 升级的实施范围、逐阶段改动、验证结果与剩余边界。

运行：`npm install` 后 `npm run dev:desktop`；浏览器预览可运行 `npm run dev`。`npm run verify` 执行文档、单元、构建和界面测试。浏览器草稿存于当前浏览器本地存储，正式留存请使用“保存项目”导出 JSON 快照。
